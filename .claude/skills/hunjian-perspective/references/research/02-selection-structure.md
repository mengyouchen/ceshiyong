# 02 · 台词挑选与排列结构（逐份拆解）

> 来源：用户一手素材。下面的"功能"标注是**我的推断**，台词本身是用户原文。

## 一、开场第一句（9/9 都不是交代背景）

| # | 第一句 | 类型 |
|---|---|---|
| 1 | 我想告诉你 / 你把我的躯体和灵魂都占据了 / 我爱 我爱 我爱你 | **高潮前置**：把全片最高点（告白）放最前面，再倒回去讲冲突 |
| 2 | 你能帮我个忙吗？装作是我的好朋友 | **关系请求**：一句话立起两个人的关系 |
| 3 | 你来这里做什么 | **质问**：对方不信任，主角要证明自己 |
| 4 | 我离开了 | **结局前置**：先说结果，后面全是"为什么" |
| 5 | 我喜欢一个人 / 却不能告诉任何人 | **秘密告白** |
| 6 | 大家都觉得我很蠢 / 你才不蠢 | **关系确认**：一个被看低，另一个站出来护着 |
| 7 | 我不爱我的老婆 | **反常宣言**：主题句（不是不爱，而是太爱）正好把这句翻过来 |
| 8 | daddy daddy / 怎么了宝贝 / 你看不见我们身上着火了吗？ | **噩梦钩子** |
| 9 | 紫色是王冠的颜色 | **意象句**：一个符号点出全片（权力、王冠） |

规律：第一句必须让人"想知道为什么"。五种开法：高潮前置、结局前置、秘密/反常宣言、关系请求/确认、意象句。

## 二、中段：三拍推进

几乎每份都按这个顺序走：

1. **建立关系**（两个人怎么连上的）：2 的"你为什么选择我/是你选择了我"，5 的"我还以为在新班级里也交不到朋友呢"，6 的"你才不蠢"。
2. **外界压力/伤害**（第三方的声音）：4 的"不懂英语就别讲""垃圾""你是不是偷钱"，5 的"你为什么要和他说话啊 真是晦气的家伙"，6 的"她是凶手"，3 的"看来他根本做不到"。
3. **情感爆发**（一句直给的心里话）：1 的"我做这一切都是为了你"，2 的"你所经历的一切我愿意承担一半"，4 的"如果我们离婚了一定是因为你"，8 的"我的心已经支离破碎……我爱你"。

**外界的声音**常常是短促的判词（垃圾 / 她是凶手 / 无罪释放 / 晦气的家伙），一行就是一刀，和主角的长句形成对比。

## 三、结尾最后一句（轻收）

| # | 最后一句 | 收法 |
|---|---|---|
| 1 | 如果你的感觉有所改变的话 / 我今天起便不想和你分开 | 承诺（唯一的圆满） |
| 2 | 我真的太累了 / 我总是很累 / 很累 | **暗示死亡，不说破**，主题句"停留在了那个夏天"补上答案 |
| 3 | 你想抱抱她吗？ | **小动作收大主题**，一个温柔的问句 |
| 4 | 再见了日记 / 对不起 | 暗示轻生，不说破 |
| 5 | 我们转世重生了吗 / 我觉得没有 / 我们还是跟原来一样 / 这样啊 / 太好了 | 释然 |
| 6 | 母亲临终前 / 我向她许下承诺 / 会保护好你 丽兹 | **最后揭底**：全部行为的动机放在最后一句 |
| 7 | 如果是雨天你不会见到我 / 如果是晴天你会想到我 | 逝者留下的话，诗意 |
| 8 | 我受不了了 | 崩溃，一句短话 |
| 9 | 我喜欢你的脖颈儿 | **反讽**：甜言蜜语，熟悉历史的观众知道她会被斩首 |

规律：9 份里没有一份用"大道理"收尾。最后一句通常比中段更短、更轻、更日常，越轻越疼。死亡从来不直说（2、4、9），留给主题句或观众补。

## 四、片段内部

- 每个片段 1–3 行为主（平均 2 行），空一行就是一刀。
- **问答对**是最常见的单位：你为什么选择我 / 是你选择了我；你明天回来学校吗？/ 也许吧；那你是什么感觉（问而不答）。
- 回答经常是**反着接**或**避开**：是你选择了我（反转主客）、也许吧（回避）、我觉得没有（否定后释然）。
- **保留重复**作节奏：我爱 / 我爱 / 我爱你；看漫画 ×2 + 看啊 ×3；很累 / 很累；daddy daddy。推断是给配乐卡点用的。
- **一行一个意群**：长句拆成多行（"我长大后 / 一定无法变成我想成为的大人"）。
- 不写说话人、不写引号、不写旁白、不写画面说明。只有台词。
- 外语原声保留：4 的"mom，your cup of water。/ Thank you jie。"保留，因为下一句"是glass of water，不是cup"是羞辱的关键。外语本身就是剧情点时才保留。
- 称呼保留：达西先生、嘿，队长、丽兹。称呼放在情绪最重的一句里（"会保护好你 丽兹"）。

## 五、主题句与台词的关系

| 关系 | 例子 | 说明 |
|---|---|---|
| **台词原话/近似原话** | 4（主题句≈倒数第二段）、8（"我受不了了"≈"我走不出来"）、1 | 主题句是角色心声，直接从台词里来 |
| **补位：说出台词没说的** | 2（夏天/死亡）、9（玫瑰/野性）、3（意志） | 台词只给过程，主题句给结论 |
| **翻转开场句** | 7（"我不爱我的老婆"→"不是不爱，而是太爱"） | 主题句推翻第一句，看完才懂 |
| **给片名下定义** | 5（"……他们就把它叫做怪物"）、9（都铎王朝最娇艳的玫瑰） | 重新解释片名里的那个词 |
| **意象/格言** | 6（一滴眼泪的重量） | 抽象一层，不直接对应某句台词 |

## 六、一片多题（《破碎人生》×2）

同一个片名做了两版：一版主题"不是不爱，而是太爱"（选麻木、隐藏情绪、怀孕的秘密、逝者留言），一版主题"对不起，我走不出来"（选噩梦、火灾自责、心碎道歉、崩溃）。两版台词零重合。说明用户是**先定主题，再按主题挑台词**，不是先挑名场面再起标题。
（注：#8 的台词疑似出自《海边的曼彻斯特》，见 01 文件，但"先定主题再挑台词"这条结论不受影响。）
