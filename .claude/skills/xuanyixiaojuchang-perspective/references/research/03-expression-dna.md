# 03 · 表达 DNA

> 来源：25 篇一手文案的逐行统计 + 人工标注。

## 句式硬指标

- **一行一个意群**：每行均 8.9 字、中位 9 字；597 行里只有 40 个逗号。句子被切成动作单元：
  ```
  她皱了皱眉
  退回屋里
  ```
- **动作动词开头/结尾**：看、走、按、拽、推开、掏出、瘫、跪。几乎没有形容词堆砌。
- **对白不加引号**：先一行"谁 + 怎么说"，下一行直接接台词：
  ```
  男孩拽了拽他的衣角说
  妈妈，我们家在16楼
  ```
  修饰语放在"说"前面："低头温柔的说""忍住泪水坚定的说""沙哑着声音说"。
- **第三人称全知、过去时叙述**，没有"我"，没有和观众对话，没有"家人们""你猜怎么着"。

## 人物称呼

零人名。称呼 = 身份标签，而且一篇里保持不变：
男子、女孩、小伙、小伙子、帅气小伙、精致女孩、小两口、小情侣、一家三口、老父亲、30岁的壮汉、老板娘、老顾客、包工头、护林员、老警员、民警、秘书、主管、大一新生、学姐。
→ 标签自带人设（"精致女孩"做吃播、"30岁的壮汉"逼老父亲）。

## 情绪词表（按出现位置）

| 位置 | 用词 |
|---|---|
| 中段起疑 | 有些疑惑、觉得好奇、半信半疑、奇怪的是、越想越不对劲 |
| 转折触发 | 突然、忽然、这时、谁知、可、却 |
| 冲击瞬间 | 愣住、僵住、瞳孔一缩、头皮发麻、后背一阵发麻、脸色发白、脸色骤变 |
| 收尾身体 | 瘫在地上、双腿一软、跪在了地上、瘫坐到地上、崩溃大哭、嚎啕大哭、泪流不止、半天没回过神来 |
| 化解类 | 灵机一动、瞬间化解了尴尬、瞬间解除了危机 |

高频："瞬间"9 次、"愣"8 次、"突然"8 次——几乎每篇至少一次。

## 标题公式

| 公式 | 例子 | 作用 |
|---|---|---|
| 引用最刺耳的一句台词 | "可18楼已经封了三年了"、"听说你们宿舍有个女生特别烦人" | 标题即钩子，有时还是谜底 |
| 反讽/加引号 | 真是太"幸运"了、活该你升职加薪、这是个好秘书、"女友"开口的那一瞬间 | 预告反转但不说方向 |
| 反问把问题丢给观众 | 这是谁的问题？、这只是一碗粥的事儿吗？、走丢的到底是牛还是牛主人？ | 引导评论站队 |
| 情绪预告/挑衅理解力 | 这是一个悲伤的故事，看不懂挺好、不同角度解读有不同的答案 | 激发"我要看懂"的好胜心 |
| 物件+形容词 | 诡异的衣柜、反锁的卧室门、坠崖的情侣、包子铺的特殊规矩 | 悬疑物件直给 |
| 结果式感叹 | 只是洗了个澡怎么会这样、拯救了面子却重伤了里子 | 先给结局的情绪 |

标签：#原创动画 #推理 #悬疑 #反转 #万万没想到 #搞笑 #温情 #ai动画 —— 题材标签 2–4 个。

## 幽默方式

- 反讽（"幸运"、"好秘书"）
- 黑色小包袱放在温情结尾后面（牛主人："下次让大家尝尝自制的牛肉干"）
- 职业错位（医生笑着报"阳性"）
- 不自嘲、不玩谐音梗、不打破第四面墙

## 转写噪声（不要模仿）

语料是 ASR/字幕转写，有明显错字和人称错乱：
- 他/她频繁串用（"男子…她吓了一跳"(5)、"男孩…她努力勾起头"(10)）
- 错字："犀牛乱撞"(18，应为小鹿乱撞，也可能是故意玩梗)、"按摩水和食物"(10)、"把香药"(14)、"老爸你姓送来的"(6)
→ 创作时人称必须前后一致；这些不是风格。
