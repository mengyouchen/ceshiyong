# 02 · 结构骨架分析

> 来源：25 篇一手文案。所有结论都附了篇号（见 01-corpus-catalog.md）。

## 通用六拍骨架

几乎每篇都能切成下面六拍，只是长度不同：

| 拍 | 功能 | 行数占比 | 语料证据 |
|---|---|---|---|
| ① 定人 | 一句话交代"谁 + 在哪/在干嘛"，用身份标签，不用人名 | 1–2 行 | "一家三口走进电梯"(2)、"小伙子发现新婚妻子有个习惯"(8)、"包子铺的老板娘有个奇怪的规矩"(7) |
| ② 立反常 | 抛一个不合常理的规矩/现象/要求 | 2–5 行 | 反锁卧室门(8)、打包三个堂食两个(7)、只坐到18楼(23)、衣柜复制(18)、逼父亲磕头(14) |
| ③ 加码/重复 | 反常重复出现或层层加重，常见"一连好几天""每次" | 3–8 行 | "一连好几天都是这样 / 每次看的正投入 / 那股臭味就会飘来"(1)；"每天坚持…每次回来"(10) |
| ④ 打破 | 一个意外打破规律：提前回家、有人跟踪、救援来了、东西掉出来 | 2–5 行 | 提前结束出差(8)、妈妈提前等在18楼(23)、脚下一滑照片掉出(5)、救援绳子顺下来(10) |
| ⑤ 递信息给角色 | 关键信息以"物件/一句话/一个画面"交给角色 | 1–3 行 | 泛黄的告示(7,23)、合照(5)、卷宗(17)、签字单(25)、纸条(22)、"一句话"(3,11,13,24) |
| ⑥ 身体收尾 | 只写身体反应，不写心理解释 | 1–2 行 | 瘫在地上(1)、跪在了地上(17)、后背一阵发麻(8)、脸色骤变当场崩溃(18)、瘫坐到地上泪流不止(25) |

**关键观察**：第 ⑤ 拍是整套结构的枢纽。信息"递给角色"而不是"说给观众"，是这批文案和普通故事号最大的区别。

## 三种结局形态

### A. 藏底式（14/25，主力）
⑤拍的内容不写出来 → ⑥拍只写反应 → 观众被迫去评论区找答案/争答案。
标志句式：
- "她突然意识到什么"(1) / "小伙突然明白了什么"(8)
- "看到单子上的内容 / 她愣住了"(25)
- "看到里面的场景 / 脸色骤变"(18)
- "小哥淡定的说了一句话 / 瞬间化解了尴尬"(11) / "飞快打了两行字发出去 / 瞬间化解了尴尬"(13)

### B. 揭底+再翻一层（2、12、14、25）
先给一个答案让观众松一口气，再补一个镜头推翻/加深：
- 18楼：揭"儿子死了" → 监控室"只有男人一个人抱着空气"
- 狗：本地人揭"老演员" → 店铺老板"意味深长的笑了"
- 父亲：父亲死了（观众以为是被逼死/病死）→ 倒叙"磕头借寿命"，逼跪变成孝
- 谁的问题：揭"其实是妻子不孕" → 再揭签字单

### C. 显性单揭底（6、9、16、22）
一句台词/一张纸条/一段解释说破。适合搞笑、科普、情感题。

## 时间推进词（跳剪用）

第二天(1,23) / 一连好几天(1) / 不知过了多久(9) / 就这样，两人又撑了半个月(10) / 有天(8) / 深夜(8) / 直到3年后的一天(25) / 事后(14) / 周一早上(6)
→ 规律：用一个时间短语独占一行做转场，不写过渡。

## 倒叙用法（14）

先抛最刺眼的"果"（30岁壮汉逼父亲下跪），中段让父亲死亡，最后一句才给"因"（偏方）。
倒叙把"恶行"变成"孝行"——这是道德翻转最强的一种写法，语料里只有 1 例，但效果最强。

## 长度与题材

| 题材 | 行数 | 字数 |
|---|---|---|
| 搞笑/梗 | 10–27 | 104–250 |
| 高情商/职场 | 15–26 | 122–221 |
| 悬疑/灵异/推理 | 15–35 | 149–302 |
| 家庭多层反转 | 48 | 426 |

多一层反转，大概多 10–20 行。
