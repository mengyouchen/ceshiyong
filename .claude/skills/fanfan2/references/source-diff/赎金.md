物料：`fanfanshuo/字幕/赎金.ass`（片长 1:56），稿件 `fanfanshuo/《赎金》 7657530437765582116.txt`（621 行）。字幕从头读完；约 110 句英文原声用 `anchor.py` 对到时间码，`order.py` 算顺序和篇幅。

## 一、他怎么定这部片

- **一句话**：航空大亨的儿子被绑，他发现给钱儿子必死，于是上电视把赎金变成悬赏，和一个当警察的绑匪头子赌儿子的命。
- **乐趣**：两个脑子博弈。每一步棋都讲"谁想要什么、对方怎么算"。
- **观众位置**：比汤姆多。29 分钟就交底吉米是警察；血衣是假的也提前说破（372 行）。观众站在两人上面看棋。
- **镜头**：两边轮流打算盘。汤姆这边讲他的推理和赌，吉米这边讲他的"脑回路"；FBI 和凯特只在影响棋局时出现。
- **主线词**：**"赌"**——"他决定赌一把"（256）、"他赌对了"（265、434）、"一场关乎儿子性命的豪赌"（289）、"这场赌博他几乎压上了一切"（431）；外加"疑点"计数、"棋子""棋差一招""掀了桌子"。
- **台阶**：被动照办 → 第一次交易失败 → 看清"给钱必撕票" → 挂电话赌第一把 → 赎金变悬赏 → 加码到四百万、电话对骂 → 吉米上门领赏 → 汤姆看穿 → 银行 → 放下枪。

## 十一、他的思维复原

1. 博弈片——观众站在两人上面看棋：谁是绑匪早点交，诡计（血衣）也可以提前说破。
2. 钩子取最反常的一步棋，再加一拍更离谱的（对骂），然后倒回去用主角自己的广告立人物。
3. 每一段只问一个问题：**这一下有没有改变棋局？** 改变了（换车、上电视、挂电话、加码、去银行）就讲细、留原声；没改变（主题独白、夫妻互怪、侦查支线）就删。
4. 反派延后亮相，先顺着"好警察"写一个假象，再一句翻过来。
5. 把观众的推理组织成"疑点"，并提前到事发那一刻埋下。
6. 原片里的一个比喻（摩拉人）和一句台词（"押付钱的人"），删掉出处，把"赌"拎出来做全篇的主线词。

## 十二、这一部最值得学的

- **博弈片的取舍标准是"这一下有没有改变棋局"。**
- **重排信息，不重排场次**：把后面才揭开的真相（血衣）、后面才说出口的推理（疑点）提前到事发那一刻。
- **反派的身份可以比原片更晚亮，并且先顺着观众的期待写一个假象。**
- **主线词可以从原片一句被删掉的台词里拎出来**（"赌"）。
- **可再斟酌**：删了吉米最后的威胁（"今天吉米会来吗"），汤姆想亲手处决他就少了一层理由；删了凯特"我要你付钱"，她站到丈夫一边的分量也轻了。
