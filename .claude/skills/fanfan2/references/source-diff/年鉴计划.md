## 一、他怎么定这部片

- **一句话**：几个高中生在亡父的地下室里造出时光机，越用越上瘾，每改一次过去就多一场灾难，最后只能回到起点毁掉它。
- **乐趣**：规则片 + 开场谜题（录像里的另一个自己）守到结尾闭环。
- **观众位置**：和大卫一样多；他独自穿越的那几次，观众比朋友们知道得多。
- **镜头**：钉在大卫身上。
- **台阶**：发现 → 造出 → 第一次穿越 → 立规矩 → 尝甜头（考试、复仇、彩票）→ 音乐节 → 独自破规矩 → 蝴蝶效应 → 越补越坏 → 杰西消失 → 回到七岁生日 → 毁掉机器 → 新时间线。

## 五、哪里讲细、哪里一笔带过

- **讲细的**：造机。每一次失败、每一次"对上了"都讲，因为观众得一步步相信"真能造出来"。
- **后半的灾难链每一环一句**：灾难本身不新，新的是它们怎么连起来。
- **结尾评论长**：他明说不讲空道理，最后落在一笔具体的交换上。

## 六、他自己加的

- "17岁生日"（让开头和"七岁生日"对称）。
- 规矩第三条。
- "原来从一开始竟然就是他自己"的解读。
- 结尾拒绝空话、讲因果闭环。

## 七、讲错、讲偏

- 原片发现录像那天不是大卫的 17 岁生日。
- 大卫回去时"不是为了救下莫名身亡的父亲"——原片里他从一开始就想救父亲（58:45"你觉得你能回去拯救他/那就是我在努力的"），只是最后放弃了；他删了前面那句，这里的"不是为了"就显得突然。

## 八、他的思维复原

1. 开场谜题够强——直接当钩子，原片真正的开场（麻省理工）删掉。
2. 造机过程要讲足，观众才信。
3. 规矩立了就要破——"制定规则的人成为首个打破规则的人"。
4. 灾难链一次讲清因果。
5. 闭环的答案放到最后一次说出，埋设可以不埋。
6. 结尾不说空话。

## 九、这一部最值得学的

- **原片自己的开场谜题够强时，可以删掉它之前的"真正开场"，让谜题成为第一场。**
- **闭环片：答案放在最后一次说出（"原来从一开始就是他自己"），前面的埋设可以省。**
- **主角立的规矩，破的时候明写一句。**
- **可再斟酌**：删掉手表的来历后，"回去救父亲"这条动机就没了；最后"不是为了救父亲"的那个转身少了分量。
