# 《时间旅行者的妻子》原片字幕 ↔ 凡凡稿 逐段对照（深度版）

物料：`fanfanshuo/字幕/时间旅行者的妻子.ass`（片长 1:39），稿件 `fanfanshuo/` 中《时间旅行者的妻子》稿（581 行）。字幕从头读完；约 107 句英文原声用 `anchor.py` 对到时间码（20:58、22:15、36:23、42:07、54:23 等是短句误配，已剔除），篇幅按稿件行段人工统计。

## 一、他怎么定这部片

- **一句话**：一个控制不了自己穿越时空的图书管理员，被一个从六岁起就认识他的女人爱着；他们知道结局（他会死），却改变不了。
- **乐趣**：注定的悲剧。观众听的不是"会怎样"，而是"怎么到那一步"。
- **观众位置**：比亨利、克莱尔都多。中枪的中年亨利、岳父打猎，他都明着标"隐患""死期将至"。
- **镜头**：主要跟亨利；克莱尔的童年攒成一块，从她的角度讲。
- **主线**：等待——克莱尔"只能做一个被动的等待者"；结尾"用爱去填充等待时光"。
- **结尾**：用这部片自己的比喻——亨利是图书馆管理员，"人生就像一本被剧透的书"。

## 九、他自己加的

- 一场拆两半："又踏上了那班熟悉的列车"。
- 明着标伏笔："第一个也是最关键的隐患"、"这一幕意味着亨利的死期将至"。
- "等待"的画面串：快递、空盘子、烂摊子。
- 把消失讲成喜剧："看球赛的时候……那条线变成了直线"。
- 女儿"光速变脸"。
- "他那些破碎的时间/全都揉进了这个女人的生命"。
- 结尾的比喻："一本被剧透的书"。
- "窗上逐渐淡去的掌纹"——原片画面拿来收尾。

## 十、讲错、讲偏

- 第 121 行"这仅有两次的见面"：原片克莱尔记了很多次日期（22:10 日记），18 岁是最后一次。
- 第 151–158 行把地铁一场讲成两次。
- 第 473–474 行"未来的阿尔巴……教她生老病死的自然规则"：原片那句是父母对孩子说的（1:23:27–1:23:31）。
- 第 479 行"四下无人的冰天雪地"：原片是躲进货运车厢被锁住（1:24:02–1:24:05）。
- 第 430 行"亨利才想起了自己的死期"：原片是亨利自己问"我死的时候你几岁"。

## 十一、他的思维复原

1. 注定的悲剧——伏笔明标，观众听的是"怎么到"。
2. 钩子挑"规则和代价一次演完"的那场（地铁），哪怕在 28 分钟；还拆成两半用，后半等观众知道"那个女孩"是谁再讲。
3. 克莱尔散在全片的童年攒成一块，按她的年龄讲完，再回到"假装第一次见面"。
4. 配角（戈麦斯）推迟到需要他时登场，前情压成一句。
5. 解释性的戏（医生、日记、鸡生蛋）一律压到最少。
6. 原片只有一句的情绪（等待），他配一串画面。
7. 结尾用这部片自己的比喻（图书馆管理员 → 被剧透的书）。

## 十二、这一部最值得学的

- **钩子挑"规则和代价同时出现"的那一场，哪怕它在第 28 分钟；一场戏可以拆成两半，前半做钩子，后半留到观众听得懂的时候。**
- **散在全片的、同一个人的过去，可以按那个人的时间顺序攒成一块讲完。**
- **注定的结局，伏笔明着标；要猜的结局，伏笔不标。**
- **原片只给一句的情绪，可以配一串具体的画面。**
- **可再斟酌**：删了"我唱不好"和"我不想让你一生都在等待"，原片首尾的两个回声都没了；18 岁那一吻挪走后，结扎和初吻之间的因果也断了。
