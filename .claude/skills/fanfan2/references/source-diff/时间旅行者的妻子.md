## 他是怎么取舍的

1. **钩子挑的是"把规则和代价一次演完"的那场。** 地铁上见到死去的妈妈：能见到过去的人（规则），改变不了（代价），还认不出他（痛）。不挑开头的车祸，因为车祸只给了规则。
2. **一场戏拆成两半用。** 地铁那场前半做钩子，后半（"我遇见一个女孩"）留到他真正爱上克莱尔以后再讲，这时观众才听得懂这句话的分量。
3. **线索散在全片的童年草地，攒成一块。** 原片三次草地戏分别在第 14、45、64 分钟；他按克莱尔的年龄顺序串在一起，紧接在"图书馆初见"后面讲完，再回到"假装这是初次见面"。观众一口气知道了克莱尔这边的全部。
   代价：18 岁那一吻原本是结扎之后的亨利去的，两件事在原片里有因果，他拆开后这层因果没了。
4. **注定的悲剧可以明着埋伏笔。** 岳父打猎、中枪的中年亨利，他都直接标出"隐患""死期将至"。这和解谜片里线索不打标记正相反：这部片的乐趣不是猜结局，而是看一个早就知道的结局怎么到来，所以伏笔越亮越揪心。
5. **鸡生蛋的悖论删。** 医生是谁介绍的，原片绕了一圈；他只说"妻子介绍的医生"。这里的悖论不推动剧情，讲了反而打断"想要孩子"这根线。（对比《环形使者》他主动加讲祖父悖论——那里悖论正是两个乔谈崩的原因。）

## 重排

- 第 28 分钟的地铁 → 片头钩子；开头的车祸 → 钩子后的来历。
- 婚礼后的童年对话、结扎后的初吻 → 都挪进"克莱尔的童年"一块。
- 戈麦斯撞破秘密 → 推到婚礼上他帮忙打掩护时，压成来历。
- 父亲那场的戒指 → 挪到求婚。

## 他自己加的

- "等待"的画面串（快递、空盘子、烂摊子）——原片只有一句"我在这里等你两周"。
- 结尾的比喻："亨利的人生就像一本被剧透的书/他知晓一切/却无法改变一切"——他是图书馆管理员，这个比喻换一部片就不成立。
- "窗上逐渐淡去的掌纹"——原片的一个画面，被他拿来收尾。

## 讲错、讲偏

- "这仅有两次的见面"：原片克莱尔记了很多次日期，最后一次是 18 岁。
- "教她生老病死的自然规则"的是未来的阿尔巴——原片那句是父母对孩子说的。
- 冻伤：原片是躲进货运车厢被锁住，不是"四下无人的冰天雪地"。

## 这一部最值得学的

**钩子挑"规则和代价同时出现"的那一场，哪怕它在第 28 分钟；一场戏可以拆成两半，前半做钩子，后半留到观众听得懂的时候。**
**散在全片的、同一个人的过去，可以按那个人的时间顺序攒成一块讲完。**
**注定的结局，伏笔明着标；要猜的结局，伏笔不标。**
