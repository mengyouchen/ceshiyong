## 一、他怎么定这部片

- **一句话**：一个普通保安在一场无人生还的火车事故里毫发无伤，一个骨头像玻璃一样脆的漫画画廊老板找上他，说他是超级英雄。
- **乐趣**：跟着主角慢慢相信 + 最后一刀反转（玻璃人就是制造灾难的反派）。
- **观众位置**：和大卫一样多。
- **镜头**：主要钉在大卫身上；伊利亚只在他找上门、摔下楼梯时有自己的段落。
- **台阶**：只有一条——"信不信"：当成巧合 → 半信半疑（球场、举重）→ 被溺水推回去 → 终于相信（废车场）→ 去人群里。
- **他删掉的那条线**：婚姻。原片把"他为什么每天醒来都悲伤"的问题和答案都放在这条线上。

## 十、讲错、讲偏

- **结尾的道理和原片相反。** 原片：大卫每天醒来就悲伤，是因为他放弃了天赋去过平凡日子（1:03:26–1:03:31）；接受自己之后悲伤消失（1:38:29"没有"）。他的结尾却说"平凡度日的保安……才是多数人最该珍惜的状态"。原因是婚姻线和"悲伤"那句一起删了。
- 第 240 行"最终儿子并未有勇气扣下扳机"：原片是大卫用"你要是扣动扳机，我就搬去纽约"劝下的（1:01:40）。
- 第 369–370 行"这件事最好还是别让妻子知道"：原片奥黛丽在约会时已经说过"你的身体是上天的恩赐"（1:10:14），她是知道的。
- 第 287 行"还在营救妻子时"后面断了半句，转写缺失。

## 十一、他的思维复原

1. 跟着主角慢慢相信——只走"信不信"这一条台阶，凡是推这条台阶的都留。
2. 序幕挪到主角心里冒出问题的那一刻，人物借问题进场。
3. 一个人的一件事讲完再换人（伊利亚跟踪 + 诊断）。
4. 揭底前的明示（伊利亚母亲的话、伊利亚自己列出的灾难）删——这和《宿敌》删黑格尔、《千钧一发》删拉马尔的儿子是同一个判断。
5. **反面**：为了台阶干净，把婚姻线整条删了；可这部片的问题（悲伤）和答案（接受自己）都长在婚姻线上。结尾只能自己找一个道理，找反了。

## 十二、这一部最值得学的（反面）

- **删线之前，先看清片子把"答案"放在哪条线上。** 这部片的问题和答案都在婚姻那条线上；删了它，结尾就会落空。
- **问题和答案要么都留，要么都删。** 他删了"醒来就悲伤"，却留了"还悲伤吗/没有"——只剩答案，观众不知道它在回答什么。
- 删掉的线里如果装着结尾要回答的问题，至少留一两处："悲伤"那一句，和"你是为了她才假装受伤"那一句。
- **对的那一半**：反派的自白和揭底前的明示，删得干净。
