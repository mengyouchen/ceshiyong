# 《天才瑞普利》原片字幕 ↔ 凡凡稿 逐段对照（深度版）

物料：`fanfanshuo/字幕/天才瑞普利.ass`（片长 2:19），稿件 `fanfanshuo/10.txt`。字幕从头读到尾，英文原声用 `anchor.py` 对时间码。

## 一、他怎么定这部片

- **一句话**：一个借了件外套的穷小子，被富豪派去劝儿子回家，结果爱上了那种生活，为了不被赶出去，杀了那个儿子、变成了他。
- **乐趣**：看一个人坠落；还带"他会不会被识破"的悬念。
- **观众位置**：比所有人都多——每一次冒名、每一次杀人观众都在场。
- **镜头**：钉在瑞普利身上。
- **台阶**：借外套 → 冒充同学 → 住进迪基家 → 被嫌弃 → 第一次杀人 → 变成迪基 → 第二次杀人（弗雷迪）→ 嫁祸给"迪基" → 恢复瑞普利、继承财产 → 第三次杀人（彼得）。
- **重复的钉子**："只用了三秒就决定痛下杀手"（玛吉那次、彼得那次）。

## 五、哪里讲细、哪里一笔带过

- **讲细的**：第一次杀人之前。瑞普利一次次被羞辱、被冷落，他都讲，第一次杀人才有来路。
- **每一个诡计都讲透**：香水、约在同一个地点、引开警察、遗书。
- **结尾很短**：坠落已经讲完，最后只落一个画面。

## 六、他自己加的

- "三步速成富二代"的问题式开头。
- 时代背景（晒黑代表有钱、天主教的重罪）。
- 迪基、弗雷迪、希尔瓦娜各自的心思（"异常放松""下定了决心"）。
- 结尾给每个配角一个隐喻。

## 七、讲错、讲偏

- 主角的代词"他/她"混用（转写）。
- "那人的未婚妻他也想据为己有"：原片冒名后和梅瑞迪斯周旋，并没有想要玛吉。

## 八、他的思维复原

1. 坠落片——钩子从"已经越线"开始，再用原片自己的"借一件外套"倒回去。
2. 第一次杀人要有来路——前面把每一次羞辱都讲足。
3. 每个诡计都要讲清他怎么想的，观众才觉得他是"天才"。
4. 原片的心理比喻（地下室）和题眼（虚假的大人物）都不用；结尾他用"空洞"自己收。

## 九、这一部最值得学的

- **坠落片：钩子从第一次越线之后讲起，原片自己的"起点句"留着当倒叙的入口。**
- **第一次越线之前给足羞辱，越线才有来路。**
- **同一种越线第二次出现，用同一句话再说一遍（"只用了三秒"）。**
- **证据的埋设（戒指的誓言）可以删，兑现时由角色的原声补出。**
- **可再斟酌**："宁做虚假的大人物，不做真实的无名小卒"是原片自己的话，用它收结尾比"空洞"更只属于这部片。
