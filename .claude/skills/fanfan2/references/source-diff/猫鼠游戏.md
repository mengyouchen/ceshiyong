# 《猫鼠游戏》原片字幕 ↔ 凡凡稿 逐段对照（深度版）

物料：`fanfanshuo/字幕/猫鼠游戏.ass`（片长 2:16），稿件 `fanfanshuo/16.txt`（785 行）。字幕从头读到尾，英文原声用 `anchor.py` 对时间码。
（这一版改正了旧笔记的一处判断：他不是"删掉监狱/押送的框架"，而是**把框架拆开，按时间顺序放回原位**；删掉的只有电视节目那一层。）

## 一、他怎么定这部片

- **一句话**：一个父母离婚、离家出走的 16 岁少年，靠换身份骗了几百万；追他的 FBI 探员，最后成了他真正的父亲。
- **乐趣**：看他怎么骗（骗术片）+ 猫鼠追逐。
- **观众位置**：比卡尔多——每一个骗局观众都先看到全过程；比弗兰克少——卡尔的布控，观众和弗兰克一起最后才发现。
- **镜头**：主轴是弗兰克，卡尔那条线在"他发现了什么线索"时切过去。
- **主线词**：猫和老鼠（"一只猫已经锁定了它""这只老鼠"）；节点：圣诞夜的电话。
- **结尾**：真正的主角是那只猫。

## 三、讲述顺序

**钩子（跨 37–75 分钟剪辑）** → 18 分（学校）→ 13 分（父亲的骗术，倒接）→ 14–28 分 → 29–48 分 → 50–55 分（钩子那场重讲）→ 1:06 → 0:57 → 1:03 → 1:10–1:25 → **1:18（卡尔的线，挪后）** → 1:29–1:57 → **0:05（监狱框架放回）** → **1:28 + 0:29 + 1:58（飞机框架合并）** → 2:00–2:15。

原片是"电视节目 → 监狱 → 倒叙 → 中途反复切回飞机"的三层结构。他拆掉一层（电视）、把另外两层按真实时间放回去，于是整篇变成一条顺的时间线，只在开头用一段跨片的快剪当钩子。

## 五、哪里讲细、哪里一笔带过

- **骗术一律细讲**：每一次骗，从起意、准备、现场，到对方哪里被骗住，都讲全。
- **压缩的**：父子线、母亲线、布伦达线，只留推动下一次逃跑的部分。

## 八、讲错、讲偏

- "这部2022年上映的猫鼠游戏"：2002 年。
- 卡尔在曼沙的那段（谎称外面有警察、凭女儿发誓）被压成"让他自己戴上"，两人关系转变的那一下没讲出来。

## 九、他的思维复原

1. 这部片好看在骗术——钩子就做骗术集锦，落在最漂亮的一骗。
2. 原片三层框架，耳朵跟得住吗？——跟不住。拆掉电视那层，监狱和飞机放回真实时间。
3. 弗兰克的天赋从哪来？——先讲他自己（学校），再揭"遗传老爹"，顺序倒过来更有味道。
4. 生父还是卡尔？——他选了卡尔，所以生父的口头禅、父母的爱情、给父亲的信都删，结尾只讲卡尔。
5. 圣诞夜是现成的节点，每次都点名。

## 十、这一部最值得学的

- **原片的多层倒叙框架可以拆：删掉最外层，其余按真实时间放回去；钩子另用一段跨片快剪。**
- **钩子那场可以在原位置再讲一遍，原声再放一次。**
- **天赋和来历可以倒着讲：先演他自己的本事，再揭"原来是遗传"。**
- **线索的埋设可以删，兑现时一句补出（"之前说过扬基队"）。**
- **可再斟酌**："我只是个爱你女儿的孩子"是全片唯一的真话，和"卡尔才是父亲"同一个主题，留下会比只留狗的笑话更好。
