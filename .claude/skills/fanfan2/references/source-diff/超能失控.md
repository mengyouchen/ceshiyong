# 《超能失控》原片字幕 ↔ 凡凡稿 逐段对照（深度版）

物料：`fanfanshuo/字幕/超能失控.ass`（片长 1:23），稿件 `fanfanshuo/` 中《超能失控》稿（363 行）。字幕从头读完；约 64 句英文原声用 `anchor.py` 对到时间码（"oh my god""holy crap""oh shit"等短句误配较多，已人工剔除）。

## 一、他怎么定这部片

- **一句话**：一个被霸凌、被父亲打、母亲快死的高中生，和两个朋友在地洞里得到念力；他越用越强，最后成了怪物。
- **乐趣**：看一个人坠落。
- **观众位置**：比安德鲁多——钩子就交底"反社会人格加超能力等于什么"，观众一路看着他往下走。
- **镜头**：钉在安德鲁身上；马特只在劝他、追他、杀他时出现。
- **台阶**：被欺负的小透明 → 得到能力 → 恶作剧 → 第一次伤人（推车进河）→ 立规矩 → 学会飞（最高点）→ 才艺秀成了焦点 → 派对上出丑 → 打父亲 → 雷劈死史蒂夫 → 拔牙"顶级掠食者" → 抢钱 → 母亲死、父亲怪他 → 吊起父亲 → 被马特杀死。
- **结尾**：把蜘蛛侠那句话反过来："能力越大，黑化越重"。

## 三、讲述顺序

原声在原片里的位置（按稿中出现的先后，剔除误配后）：06:25 → ⤳54:31–55:33（钩子）→ ↶04:24 → 14:00 → ⤳26:24（能力块）→ ↶29:01 → 30:52–32:17 → 33:13 → 35:03 → 36:41 → 47:40 → 55:21–59:55 → 1:02:55 → 1:06:03 → 1:06:14–1:16:00 → 1:23:33。

- 钩子取 55 分钟，倒回开场。
- **他自己动的一处**：散在 16–42 分钟的能力展示（乐高、摄像机悬空、煎饼上画脸、屏障）攒成一块，放在"发现能力"之后、"洞塌了"之前；之后恶作剧、推车、立规矩、学会飞照原片顺序走。
- 55 分钟起顺讲到底——那是坠落开始的地方。

## 十一、他的思维复原

1. 坠落片——钩子取第一次越线（打父亲），用一个问题交底，原位置再讲一遍、原声重放。
2. 能力的来源讲完，就把它能做什么攒成一块讲完；之后按原片走。
3. "他为什么会这样"的心理底子删，只留看得见的处境（被霸凌、被打、妈妈要死、买不起药）。
4. 配角的性格线（马特的哲学）删。
5. 坠落前的最高点只留一个（学会飞），讲足。
6. 埋设（西藏）删，兑现时一个定语补出。
7. 结尾用别人的名言反过来说。

## 十二、这一部最值得学的

- **坠落片的钩子取中段那一下"第一次越线"，原位置再讲一遍，第二遍观众听的是怎么走到这一步。**
- **埋设的那场对话可以删，兑现时用一个定语补出来**（"一直向往的西藏"）。
- **能力片：来源讲完，把能力展示攒成一块讲，再进入"用能力做什么"。**
- **可再斟酌**：删了"或许我想要有一层障碍"和父亲的过去，安德鲁的坠落少了根；删了马特的两次"我爱你"，结尾的 *goodbye Andrew* 少了分量。
