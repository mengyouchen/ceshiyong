## 一、他怎么定这部片

- **一句话**：一个酒驾前科、发誓戒酒的准爸爸，坐上陪审席才发现被告替的是自己的罪；他要在"救一个无辜的人"和"保住自己的家"之间选。
- **乐趣**：观众知情（主角就是真凶），看他在不知情的人中间怎么撑、怎么选。
- **观众位置**：比所有角色都多——钩子第一句就交底。
- **镜头**：主要钉在贾斯汀；第二条线是检察官费思（她慢慢查到他）。陪审室里的其他人只作为"压力"出现。
- **台阶**：他自己发明的"修罗场"——法庭（第一个）、陪审室（第二个）、家（第三个）、宣判（最后的）。

## 三、讲述顺序

12–16（钩子）→ 18（新闻）→ **01–03（倒回家里）** → 06–09（遴选）→ **04（捡东西，挪后）** → 16 → 20–35 → **03:25 的竞选挪到 34** → 38–47 → 47–52 → 55–1:01 → **52（酒吧，挪后）** → 1:02–1:15 → 1:18–1:24 → 1:28–1:48。

他动了四处顺序：钩子提前；开场家庭戏倒回；费思的竞选和私交各挪到她需要动机的那一刻；捡东西挪到选上之后当原因。

2. 原片开场的家庭戏要不要先讲？——不要，先把"他在陪审席上、他可能是凶手"立住，再倒回去讲他有多想当个好父亲。
3. 他的过去什么时候讲？——不在开头介绍，等他在陪审室里拿出来当论据。
4. 检察官为什么要单独跟？——她是唯一可能查到他的人，是悬念的另一头。她的动机、她的私交，放在她动摇的那一刻。
5. 陪审室十二个人怎么处理？——只留会改变局面的三个（老警探、医学生、马库斯），其余是背景。
6. 结尾怎么收？——片子本身不给答案，那就把留白列成问题，再落到良心。

这一次他在第 5、6 步之间漏了一件事：陪审室里最后改变局面的不是那三个人，是贾斯汀自己。

## 十一、这一部最值得学的

- **观众知情的片子：第一句交底，中途点一次"只有我们知道"。**
- **主角的过去先留一句不解释的原声（"given your history"），等他亲口拿出来当论据时再讲。**
- **一个配角的动机和私交，叠到她开始动摇的那一刻（费思的竞选 + 律师的话 + 老警探的话）。**
- **反面**：主角的转向必须讲出原因和动作。删戏前先问"主角最后那一下是怎么做成的"，那几场不能删。
- **反面**："请记住这个动作"标了就必须兑现。
