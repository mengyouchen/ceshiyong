物料：`fanfanshuo/字幕/少数派报告.ass`（片长 2:17），稿件 `fanfanshuo/22.txt`（597 行）。
对照方法：字幕从头读到尾；稿子每一句英文原声都用 `scratchpad/anchor.py` 对到字幕时间码，中文叙述再逐段对。

## 一、先看他怎么定这部片

- **一句话**：一个最信"预言从未出错"的警察，被预言成凶手，只能逃出系统、再钻回系统去找那份被销毁的少数派报告。
- **乐趣**：规则片 + 被追捕的悬疑。观众和约翰一样摸黑，不知道谁在陷害他。
- **观众位置**：和约翰知道得一样多；反派身份守到原片揭开的那一刻（1:53）才说。
- **镜头**：钉在约翰身上。离开约翰的地方只有三处（丹尼在现场、丹尼和局长、劳拉救人），都是在给约翰的处境补一块。
- **主线**："预言从未出错"——开头讲系统时说一次，少数派报告那里说成"最终结果依然是预言从未出错"，克罗死时"先知们的预测依然精准无误"，结尾天台的两难也是它。

## 三、讲述顺序和原片顺序

稿件里出现的原片时间，按稿件顺序排：
1:35 → 0:02 → 0:04–0:13 → 0:22 → 0:28–0:36 → 0:37–0:43 → 0:44–0:52 → 0:56–1:03 → 1:05–1:15（夹着 0:16–0:20） → 1:17–1:35 → **回到 1:35** → 1:38–1:53 → 1:54–2:01 → 2:07–2:17。

- 局长想进白宫，原片没有。
- 丹尼的死、局长的失言没讲，劳拉救人缺了原因。
- 结尾"他不过是个小人"和"他选择自我终结（保全了什么）"之间没理顺。

## 十一、他的思维复原（他在每个节点问了自己什么）

1. **这部片最好看的是什么？**——预知能力怎么用。那就把能力用得最漂亮的一场拿到最前，哪怕它在 1:35。
2. **钩子之后观众最需要什么？**——这些人是谁、这套系统怎么运转。原片开场的示范案例正好就是，照用。
3. **主角撞上的那件事在哪？**——看到自己是凶手。这里放慢，让观众和约翰一起一点点看清。
4. **主角的伤什么时候讲最疼？**——不是开头，是他逃无可逃、蒙着眼躺在黑屋里的时候。
5. **观众会在哪里绕晕？**——少数派报告的逻辑。拆成两条分支并列讲。
6. **反派什么时候揭？**——照原片，不提前；但揭之前要让约翰和丹尼各自往真相上走一步。
7. **哪些是这部片的气质、哪些是这部片的骨头？**——社会讽刺、宗教隐喻、配角来历是气质，删；规则、追捕、复仇和选择是骨头，留。
8. **结尾说什么？**——这部片 2002 年预言了今天，再落到"即使被预言也要挣扎反抗"。

这次他在第 7 步删多了一点：丹尼之死、局长失言、左轮手枪都是"骨头"，被当成"气质"删了。

## 十二、这一部最值得学的

- **钩子取规则最好看的那一场，哪怕在后半；回到原位时只说一句"接下来就发生了故事开头的一幕"，不重讲。**
- **篇幅跟着"主角的认知变了"走**：看见自己是凶手、知道系统有洞、面对仇人，这三处放慢；其余快过。
- **主角的伤口挪到他最无助的那一晚，用"原来"补出来，再顺手接到下一场（憋气）。**
- **反面**：删之前分清骨头和气质——推动因果的一枪（丹尼之死）、让配角行动的一句话（"淹死"）、给结尾埋的东西（左轮手枪），都不能当气质删。
