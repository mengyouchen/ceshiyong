# 《环形使者》原片字幕 ↔ 凡凡稿 逐段对照（深度版）

物料：`fanfanshuo/字幕/环形使者.ass`（片长 1:53），稿件 `fanfanshuo/` 中《环形使者》稿（483 行）。字幕从头读完；约 50 句英文原声用 `anchor.py` 对到时间码（有几处同词误配，已人工剔除），篇幅按稿件行段人工统计。

## 一、他怎么定这部片

- **一句话**：一个专杀"从未来送来的人"的杀手，等来了 30 年后的自己，却让他跑了；老乔要杀掉一个将来会成为暴君的孩子，小乔要杀掉老乔。
- **乐趣**：规则片（封环、失环、记忆随现在改变）+ 两个同一个人的对立。
- **观众位置**：和小乔差不多；倒带之后，观众比小乔多知道老乔的三十年。
- **镜头**：主要跟小乔；老乔的三十年和他找孩子的段落单独攒成块。
- **钩子**：把规则改写成问观众的两道选择题。
- **结尾**：把原片抽象的画外音（"那条路形成环状"）换成小乔"看见"的三个具体画面。

## 三、讲述顺序

`order.py`（剔除 33:31、50:16、17:13 等同词误配）：07:17 → 11:49 → 13:10 → 20:29 → 29:43 → 37:57 → 42:38 → 48:36 → 50:19 → 55:10 → 58:27 → 1:04:05 → 1:15:16 → ⤳1:32:40 → ↶1:34:11 → 1:38:07 → ↶(1:34–1:36 画面) → 1:41:47 → 1:46:00 → 1:48:04。

- 30:21 跟着原片倒带。
- **他自己动的几处**：
  1. "唤雨师"情报 12:26 → 48:40 回补；

## 十一、他的思维复原

1. 规则片——把规则变成问观众的选择题当钩子，设定之后补。
2. 原片的倒带结构本身就是悬念，照用（停在"一个意想不到的人出现了"）。
3. 情报（唤雨师）、规则（十五码）都延后到要用时。
4. 交叉剪辑攒成一块，放到触发它的那件事之后，用"几分钟前"接回。
5. 原片无台词的重场（消失、蒙太奇、杀孩子），他来配——画面越重越要说。
6. 原片的心理底子（乔的母亲）删了，换成更近的平行（老乔遇见妻子 / 小乔遇见莎拉）。
7. 结尾把抽象画外音换成三个具体画面。

## 十二、这一部最值得学的

- **设定片的钩子，可以把那条规则改写成问观众的两道选择题。**
- **规则讲在它兑现的那一刻**（十五码）。
- **结尾原片用抽象画外音时，换成主角"看见"的几个具体画面，再补一句因果，让观众自己把环合上。**
- **可再斟酌**：删了乔的母亲、"我不关心你儿子的死活"、"唤雨师见过母亲被杀"三处，小乔为什么能看懂这个孩子、为什么会从冷漠走到牺牲，少了根。
