## 他是怎么取舍的

1. **给一段平静的家庭戏套了一个"三道题"的框架。** 原片这几分钟只是夫妻寒暄、拥抱、说"我爱你"；他把它变成一场倒计时考试，每一题都报一次分。观众还不知道泰德要干什么，就已经在等最后一题。
2. **主角的感情线整条删。** 尼基是原片里拉扯威利"要前途还是要公道"的那个人，戏份很多。他不要这条线，直接把威利的野心说成事实（97% 的定罪率、新律所、输了就卷铺盖），再让"要不要用伪证"一场来考验他。
3. **片名的那段比喻挪到结尾。** 鸡蛋的裂纹是原片中段泰德对威利的挑衅，他留到最后，把"破绽"拆成三层（爱情的、法律的、人性的），再用这段原声收。
4. **能破案的那个疑问压住。** "他为什么那天在酒店"是原片给的提示，他只讲"脸挡住了，没意义"，到结尾才用"难怪泰德会出现在酒店的房间"揭开。博弈片里观众知道泰德是凶手、知道情人是谁，**但不知道诡计**；诡计的线索他不标。
5. **原片模糊的地方，给两个读法。** 威利为什么没用伪证，原片没说；他给"悬崖勒马"和"怕泰德有后手"两种。

## 重排

- 鸡蛋的比喻：中段 → 结尾。
- 开枪后"还要为某人送上一份大礼" → 罗伯特自杀时兑现。
- 威利对监控的疑问：中段压住 → 结尾"难怪"。

## 讲错、讲偏

- 威利的身份讲乱了："律所新人"又是"检察官"，后面"律所的颜面""律所的上司"其实是检察院；这是删掉尼基、合并两个上司的副作用。
- "身价万亿"：原片没有这个数字。

## 这一部最值得学的

**一段平静的戏，可以套一个"考题/倒计时"的框架，让观众在不知道结局时就开始等。**
**片名的比喻原片在中段说，他留到结尾当解读。**
**博弈片：谁是凶手、谁是情人都提前告诉观众，只把诡计的线索压住，最后用"难怪"揭。**
