# 《黑洞频率》原片字幕 ↔ 凡凡稿 逐段对照（深度版）

物料：`fanfanshuo/字幕/黑洞频率.ass`（片长 1:52），稿件 `fanfanshuo/` 中《黑洞频率》稿（607 行）。字幕从头读完；约 125 句英文原声用 `anchor.py` 对到时间码（12:01、15:48、29:28 等短句误配已剔除），篇幅按稿件行段人工统计。

## 一、他怎么定这部片

- **一句话**：一个警察用父亲留下的旧无线电，和三十年前、第二天就要死在火场的父亲通上了话；他救下父亲，却害死了母亲。
- **乐趣**：连锁反应。改一处过去，未来就多一场祸；父子俩隔着三十年一起去堵窟窿。
- **观众位置**：和约翰一样多；因果链讲到他想通的那一刻，原片后面才揭的环节也一起补上。
- **镜头**：两条时间线轮流走，约翰这边多讲"变了什么"，弗兰克那边多讲"怎么做"。
- **主线**：父子。母亲是"被连累的那个"，戈登是彩蛋。
- **首尾呼应**：留东西——烧焦的桌子、香烟；不留台词（"打起精神 鼓起勇气"）。

- 钩子的"难怪"——把 28 分钟铺垫压成一句。

- **因果链的最后一环**："那个病人/正是本该在这场医疗事故中死去的那个杀人魔"。
- 喜剧："高大帅气被护士那桌给注意到"。
- "当网友"、"时空快递"、"就像埋在地下的时间胶囊一样"。
- 电击陷阱的每一步。
- "一旦到了水里/那更是这些消防员的主场"。
- "不是那年戒烟/活到现在的父亲还能是谁"。

## 十、讲错、讲偏

- 第 1–2 行"刚满36岁这天""畅聊多日"：原片是父亲忌日前一晚（26:50），只聊过一次。
- 第 120 行"近10年有关父亲的记忆却依旧完全空缺"：原片是两种记忆同时存在（48:43）。
- 第 392 行"风评极佳的老警察"：原片他被卷进贪污案、被陷害背黑锅（1:22:23）。
- 第 240–251 行"那个病人就是凶手"是他的推断；原片没有一句台词明说，但前后（54:59 一针过量、凶手是警察、凶手活了下来）都指向这一点。

## 十一、他的思维复原

1. 连锁反应的片子——钩子从主角认出真相的那一秒开始（"你已经死了"），前面铺垫压成"难怪"。
2. 改过去 → 新祸：因果链在主角想通的那一刻一次讲清，连原片没明说的那一环也补上。
3. 父子线是主线，母亲线和戈登线只当"后果"和"彩蛋"——母亲和约翰在电台上的那场再动人也删。
4. 首尾呼应留东西（烧焦的桌子、香烟），不留台词（骑车）。
5. 假嫌疑人、凶手的动机——不是猜凶手的片，这些弯路删掉。
6. 原片无台词的动作戏（电击陷阱），他一步一步讲。

## 十二、这一部最值得学的

- **片子前面的铺垫可以全压进钩子里的一句"难怪……"；钩子从主角认出真相的那一秒开始。**
- **连锁反应的片子，因果链等主角想通时一次讲完，连原片后面才揭的环节也可以提前补上。**
- **首尾呼应留"东西"（烧焦的桌子、香烟），不留"台词"（打起精神 鼓起勇气）。东西比台词好兑现。**
- **伏笔不埋，兑现时一句说破**（雅虎 → "能翻身的礼物"）。
- **可再斟酌**：母亲和约翰在电台上那段，是片名"频率"最动人的一次使用，删了以后母亲只剩"被连累的那个"。
