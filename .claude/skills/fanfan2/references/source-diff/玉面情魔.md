## 一、他怎么定这部片

- **一句话**：一个害死父亲、一无所有的年轻人，靠读心术爬进上流社会，最后摔回马戏团，成了他一开始看到的那个"怪人"。
- **乐趣**：看一个人坠落；结局就是开头那个怪人，所以伏笔可以明着标。
- **观众位置**：比斯坦知道得多（开场就说破他害死父亲；他每一次"幸运"观众都听得出不对）——但在莉莉丝这条线上，观众和斯坦一样被蒙着，直到最后。
- **镜头**：钉在斯坦身上，只在法官夫妇自杀那一处离开（作为"后果"）。
- **台阶**：杂役 → 女巫的助手 → 拿到秘籍 → 唬住警长 → 私奔、成名 → 搞通灵 → 和莉莉丝合作 → 富豪 → 杀人 → 流浪 → 怪人。

## 五、哪里讲细、哪里一笔带过

- **讲细的**：骗术的演示和揭秘。皮特读手表、斯坦读警长、手提包里的手枪，每一次都"先演效果再揭方法"。这部片的爽在这里。
- **几乎不讲的**：心理和根源（治疗）。他把斯坦讲成"一个天才骗子"，不讲"一个被父亲伤透的孩子"。

## 八、原声清单（规律）

读心表演的台词（"我从不触碰它们"、"请集中注意力在这件物品上"）、皮特揭秘、布鲁诺警告、私奔邀请、警长"玛丽"、手提包里的手枪、通灵"他就在你身边"、"就这一次"、"不要写下任何东西"、测谎、"一损俱损"、"不惜一切代价"、"你们会再次在一起"、"我不需要你"、"我是爱你的"、"这些妄想"、"手提包很重吗"、"你知道什么是怪人吗"、"我生来就是干这个的"。

## 十、讲错、讲偏

- 皮特之死：原片明确是斯坦给的毒酒，他讲成幸运。
- 秘籍是泽娜送的，不是趁乱拿的。
- "一举成名的巨大伏笔"：怪人是他结局的伏笔。
- 茉莉不是一次"妥协"，中间离开过又被求回来。

## 十一、他的思维复原

1. 这是一部坠落片——**起点要狠，终点开头就标**。所以说破父亲之死，标出怪人。
2. 这部片爽在哪？——骗术。每一次骗都完整演一遍、再揭一遍。
3. 斯坦的心理要不要讲？——他选了不讲，让斯坦保持"天才骗子"的样子。代价是皮特之死、不喝酒的誓言、莉莉丝的档案都要么讲错、要么只能在结尾回补。
4. 怪人的配方放哪？——放在它落到斯坦身上的那一刻，当判决。
5. 莉莉丝什么时候翻？——照原片，最后翻；她的线索（看穿手枪、治疗、保管钱）都压住，只在翻的时候回补。

## 十二、这一部最值得学的

- **坠落片可以开场说破原片藏着的秘密；终点（怪人）第一次出现就标成伏笔。**
- **一段说明从它出现的位置挪到它应验在主角身上的那一刻，当判决。**
- **反派的线索可以全压到她翻脸时一次回补（档案、保管的钱）。**
- **反面**：原片里主角亲口承认的事（"我给他的"），不能讲成巧合；主角的戒律（不喝酒）要留，结尾破戒才有分量。读字幕时，同一件事在前后两三处出现的，一定要拼起来看。
