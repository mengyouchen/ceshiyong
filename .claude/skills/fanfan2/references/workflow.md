# 从字幕到成稿：凡凡写一部新电影的完整工作法

这份文件是 24 部电影"原片字幕 ↔ 凡凡稿"逐段对照之后，倒推出来的**操作流程**。
每一步都写了：做什么、产出什么、怎么判断、**为什么他这么判断**（来自哪几部的对照），以及他自己踩过的坑。
单篇对照在 `source-diff/`，横向总览在 `source-diff/总览.md`。SKILL.md 讲"他怎么想"，这里讲"一步一步怎么做"。

全流程分三段十二步：

| 段 | 步 | 产出 |
|---|---|---|
| **读片** | 1. 通读字幕，做场次表 | 带时间码的场次表 |
| | 2. 定片：一句话、乐趣、观众位置、镜头、台阶、主线 | 定片卡 |
| | 3. 给每一场贴标签，决定删/压/留/讲足 | 取舍表 + 删掉清单 |
| | 4. 信息调度：每个秘密、规则、往事、人物，什么时候给 | 信息调度表 |
| | 4.5 逐拍追问：每件事、每场对话的目的、原因、后果 | 发动机表 + 主角逐拍表 |
| **搭骨架** | 5. 挑钩子 | 钩子那件事 + 第一句 |
| | 6. 定讲述顺序 | 段落顺序表 |
| | 7. 哪里放慢、哪里带过 | 每段的写法 |
| | 8. 挑原声 | 原声清单 |
| **写** | 9. 按段落类型写 | 初稿 |
| | 10. 衔接 | 转场句 |
| | 11. 措辞 | 改稿 |
| | 12. 结尾与自检 | 成稿 |

**这里没有数字。** 不给比例、行数、句长、连接词频次。数字只是他写完以后稿子长出来的样子，照着数字写，得到的是长得像他的稿子，不是他的判断（第 7 步末尾说了为什么）。
每一步只问"听的人此刻需要什么、这部片的乐趣要什么"，答案就是做法。

**不要把这十二步当表格去填。** 每一步的判断都从上一步来：乐趣定错了，后面的取舍、顺序、轻重、措辞会一起错。
写坏的时候，往前找是哪一步判断错了，回到那一步重做，不要在句子上修补。

## 第一段 · 读片

### 第 1 步：通读字幕，做场次表

**做什么**：字幕从头读到尾，**先知道结局再动笔**。**字幕只有台词，所以还要查画面**：维基百科的剧情、详细的剧情梗概、影评里的场景描写，几个来源对着看（SKILL.md 〇.7 第 1 条）。
边读边记一张场次表，一场一行：

| 时间 | 场 | 在场的人 | 看得见的画面（动作、表情、道具） | 这一场里什么变了 |
|---|---|---|---|---|
| 20:34–25:27 | 车间事故 | 麦克斯、主管、老板 | 卡住的托盘、主管逼他进去、门关上、紫光 | 受致死辐射，只剩五天 |
| 35:26–37:00 | 部长和卡莱尔密谋 | 部长、卡莱尔（主角不在） | — | 重启程序的来历 |

"看得见的画面"这一列是他正文的主要原料：他讲的大多是画面，台词当原声穿插。这一列空着，写出来就只能是转述台词。

"这一场里什么变了"是关键列：主角知道了什么、得到/失去了什么、局面谁占上风、立了什么规则、埋了什么东西。
**一场戏如果什么都没变，这一列就写"无"**——它多半会在第 3 步被删。

**为什么要先做表**：字幕是按场次和台词排的，对着字幕写，稿子就会变成"下一场、他说、她说"。
《异次元骇客》照字幕写下去，原声的时间码从头到尾一次没倒回，每场都写到，转场全是"回到实验室""第二天"。
场次表让你在动笔之前，就站到片子外面看全局。

**再记一列"主角怎么知道的"**：他每一段为什么去这里、找这个人，消息从哪来（警察的留言、档案里的名单、一个姑娘的指引、报纸上的照片、他自己的推理）。
这条"得知链"一断，写的时候就只能靠复述对话去补，听的人也会问"他怎么知道的"。

**同时记下三样东西**：
- 原片自己的揭底点：每个秘密在第几分钟揭开（《升级》芯片的真相 1:29、《宿敌》同一人只在结尾暗示）；
- 原片自己的回声：同一句台词、同一件东西出现了几次、在哪（《千钧一发》"如果你还感兴趣就告诉我"50 分和 1:35 各一次；《时间旅行者的妻子》"我唱不好"片头片尾各一次）；
- 原片里**没有台词、全靠画面**的重场（《环形使者》老赛斯一点点消失、三十年蒙太奇；《千钧一发》尤金爬楼梯）——这些在字幕里只有一两行，最容易漏，却是他讲得最满的地方。

### 第 2 步：定片

写一张定片卡，六项：

1. **一句话**：一个人 + 一条规则（或一个局）+ 一个代价。说不出就回去再看（SKILL.md 第一节）。
2. **乐趣**：看一个人坠落 / 跟主角摸黑 / 被骗一次 / 找伏笔对答案 / 两个脑子博弈 / 一串误会连锁 / 注定的悲剧 / 规则+动作。一部片可以兼两种，但要定一个主的。
3. **观众位置**：比主角知道得多、一样多，还是被请来一起找。
4. **镜头**：钉在主角身上 / 两边轮流打算盘 / 顺着涟漪切。
5. **台阶**：主角从哪里到哪里，中间每一级是什么。
6. **主线**：一个反复响起的词、一件反复出现的东西、一个贴在主角身上的标签；埋在哪、收在哪。

**乐趣是总开关**，后面每一步都按它走。对照 24 部，乐趣和后面各步的对应是这样的：

| 乐趣 | 观众位置 | 钩子取哪 | 秘密怎么放 | 伏笔标不标 | 放慢的地方 | 例子 |
|---|---|---|---|---|---|---|
| 坠落 | 比主角多 | 中段第一次越线 | 开场交底 | 明着标"殊不知" | 越线的几级台阶 | 超能失控、天才瑞普利、夜行者、赛末点、玉面情魔 |
| 摸黑 | 一样多 | 原片开场的第一件怪事 | 和主角同一秒知道 | 只标"怪"，不解释 | 规则立住处、主角认知翻转处 | 源代码、不死劫 |
| 被骗一次 | 一样多（甚至一起被骗） | 原片开场的怪事 | 守到底；可疑镜头可删 | 一句不提醒，线索原样放过 | 让观众相信表面的地方 | 宿敌、升级 |
| 对答案 | 被请来一起找 | 一个小动作 / 开场谜题 | 前提早交 | 开场请找，中途指着东西提醒，兑现时"难怪" | 谜面 + 兑现 | 时空线索、年鉴计划、记忆裂痕 |
| 博弈 | 站在两人上面 | 最反常的一步棋 | 身份早交，诡计可提前说破 | 把疑点一个个摆出来（第一个疑点、第二个疑点） | 棋局翻转的那几步 | 赎金、猫鼠游戏、破绽 |
| 连锁误会 | 站在所有人上面 | 前情一句话概括 | 每一环都让观众先知道 | 用"又""却不知"拴 | 链条往前走的那几环 | 冷血追击、黑洞频率 |
| 注定的悲剧 | 比主角多 | 规则和代价同时出现的那场 | 结局早给 | 明着标"隐患""死期将至" | 最痛的一段 | 时间旅行者的妻子 |
| 规则 + 动作 | 一样多 | 规则和代价同时出现的那场 | 跟主角一起知道 | 规则讲在用时 | 规则立住 + 动作戏 | 极乐空间、环形使者、少数派报告 |

**判断错了会怎样**：在"被骗一次"的片子里请观众找伏笔，等于告诉观众有反转；
在"找伏笔"的片子里一句不提醒，观众就错过了最好玩的部分（SKILL.md 第一节）。
《异次元骇客》一版把钩子从中段取，和"摸黑"的乐趣对不上，正文倒回去讲命案，主线被推迟了一大截。

### 第 3 步：给每一场贴标签，决定删/压/留/讲足

拿场次表一场一场过。每一场先贴一个标签，再按下表处理。
**这张表是 24 部对照里他反复做的判断，"为什么"一列是对照里看出来的理由。**

| 标签 | 默认处理 | 为什么 | 例外 | 例子 |
|---|---|---|---|---|
| **主线的一步**（主角为目的做的事、对手的一步棋、链条的一环） | 留，讲意图 + 结果 | 观众追的就是这条线 | — | 赎金每一步棋；冷血追击每一次误判 |
| **规则第一次立** | 留，讲在它第一次"咬人"的地方 | 观众要能预判后面 | — | 源代码 8 分钟；升级智干"要授权才能说话" |
| **规则的原理、科学解释** | 压成一个比方 + "能做什么、不能做什么" | 原理打断推进，观众只需要能用 | 原理本身就是冲突时多讲（环形使者祖父悖论是两人谈崩的原因） | 源代码"电灯关闭后仍有余晖"；时空线索"超梦""折纸" |
| **这部片的乐趣场**（骗术、谈判、打斗、检测、造机、荒诞） | **讲足**：放慢，写他怎么想到的、对方哪里被骗住 | 观众来就是为这个 | 动作过程可压，只讲"他怎么想到的"和代价 | 升级的酒吧；千钧一发每一次检测；编号17 晚宴 |
| **主角的认知翻转**（发现真相、规则反转、看清自己） | 放慢，接一句人物反应 | 这是台阶，观众跟着反应进戏 | — | 少数派报告看见自己是凶手；源代码"他父亲叫唐纳德" |
| **交锋**（对话本身就是戏） | 原声 | 转述会把两个人讲成一个声音 | — | 赎金电话对骂；宿敌亚当结巴的长段 |
| **交代性对话**（说明、劝说、汇报、审讯里的信息） | 不复述，讲作用：说话的人要什么（写成局面）/ 听的人怎么算 / 结果（第 9.5 步） | 一句句转述就是照着翻，听的人在听别人聊天 | 最锋利的一来一回留原声 | 源代码拉特里奇"道德绑架"；赎金朗尼"温柔的威胁" |
| **埋设**（伏笔第一次出现） | 看收的时候观众需不需要记得：需要→留；不需要→删，兑现时一句补 | 埋了不需要的伏笔，只会让观众提前猜到 | 留的话，按乐趣决定标不标（见第 4 步） | 留：千钧一发游泳、银牌；删：拉马尔的儿子、西藏、雅虎 |
| **兑现** | 必留，用"难怪/原来/果然"回扣 | 观众的快感在这里 | — | 时空线索"难怪当初没有打斗痕迹" |
| **主角的心理底子**（童年、父母、为什么变成这样） | 默认删；要用时挪到他最狼狈、或亲口拿它当论据的时候 | 只讲看得见的处境，人物干净、节奏快 | **结尾要回答的问题在这条线上时，必须留**（不死劫的"悲伤"） | 删：超能失控父亲的过去、环形使者乔的母亲；挪：少数派报告儿子、陪审员2号醉驾 |
| **配角的性格线、配角自己的生活戏** | 删；配角闯进主角故事时一句来历 | 钉在主角身上，配角只是推他、照他 | 博弈片对手的算盘要讲 | 超能失控马特的哲学；冷血追击维京的家事 |
| **主角不在场的侦查、旁观者的线** | 删 | 不改变链条，还会把配角知道的信息算到主角头上 | "主角不知道的危险"留，用"几分钟前""与此同时"切 | 删：冷血追击警察线、升级尸检；留：升级菲斯克读死人的眼睛 |
| **反派独白、哲学、点题台词、片名提示** | 删 | 气质不改局面；点题会提前泄底；主题留给结尾自己说 | **独白后面要被回收当线索时整段留，标"最后再讲"** | 删：赎金《时光机器》、宿敌黑格尔、时空线索牧师；留：时空线索卡罗尔 |
| **纯抒情的长段** | 删，情感靠处境和结果讲 | 原声只放在一句话改变局面的地方 | 是主线最直接的一场时，压短也要留（他删过、可惜过：编号17 卡伊） | 少数派报告阿加莎讲肖恩的一生；年鉴计划"我会用它早点认识你" |
| **纯笑料、寒暄、过场** | 删，连它后面的回收一起删 | 不推进 | **长在推进戏上的笑料留足**（黑色喜剧尤其） | 删：冷血追击汽车旅馆的点子及其回收；留：爱斯基摩人的外号和规矩 |
| **弯路**（假嫌疑人、没教会主角东西的失败） | 删 | 不是猜凶手的片，弯路只拖时间 | **教会主角一条规则的失败留**，并替观众把规则推出来 | 删：黑洞频率戴洛、源代码冤枉工程师；留：源代码扭打时列车照样爆炸 |
| **结果不变的过程**（被杀又重来、搜查扑空） | 略过 | 观众只关心带回来了什么 | 主线台词一定留 | 源代码被枪杀略过，"一切都会好起来"留 |
| **原片的外壳、框架、开场主题画外音** | 删，或挪到结尾等画面兑现它 | 外壳不推进；主题画外音放开头是点题 | 框架本身好用（倒带、环形）就照用 | 删：猫鼠游戏电视节目；挪：赛末点擦网的球、破绽鸡蛋；照用：环形使者倒带、编号17 环形 |
| **被骗片里的可疑镜头** | 可以比原片藏得更深 | 揭底更狠 | **揭底时一定收回** | 升级自动驾驶故障、芯片展示 |
| **原片无台词的重场** | **讲满**，替观众说出画面和人物心里 | 只用耳朵听的人看不到画面 | — | 环形使者老赛斯消失；冷血追击圣诞佬被拦路；黑洞频率电击陷阱 |

**删之前必问的四个问题**（他漏过的教训）——任何一个答"是"，就不能删，最多压短：
1. 这场戏是不是这部片的**答案**？（不死劫的婚姻线装着"悲伤"的答案，他删了，结尾讲反）
2. 是不是主角**最后那一下选择**？（陪审员2号的投票转向，他删了，全片对贾斯汀的判决没了实证）
3. 是不是主角**立过的誓**、或者主角**亲口承认**的事？（玉面情魔"我给他的"被讲成"幸运"）
4. 是不是推动因果的**那一枪、那一句失言**？（少数派报告丹尼之死、"淹死"）

**再问一个问题**：这场删了，后面有没有一句台词、一个动作会失去根？
（时间旅行者的妻子 18 岁初吻挪走后，结扎和初吻之间的因果断了；超能失控删了"或许我想要有一层障碍"，坠落少了根。）
答"会"的，要么留，要么在后面那一处补一句。

**产出**：一张取舍表（每场：标签 / 处理 / 理由），和一张**删掉清单**。删掉的写下来，写稿时才不会又顺手塞回去。

### 第 4 步：信息调度

把片子里所有"观众需要知道的东西"列出来，每一样填一行：原片在哪给 → 我在哪给 → 为什么。

**再列两样东西**，这是故事讲得"合理"的底子：
- **观众心里会冒出来的"为什么"**：他为什么不直接报警？她为什么肯替他作伪证？凶手为什么要删那条留言？每一个都要在稿子里有答案，答在观众刚冒出这个问题的地方，或者揭底时一并收回。
- **片子自己的对称**：同一件事在片子里发生了两次（《异次元骇客》：格里森丢掉的那几个小时和霍尔想不起来的那一晚；阿什顿开车去找世界的边和霍尔开车去找；惠特尼死在下面、阿什顿顶上来，和大卫死在下面、霍尔顶上去）。
  对称找出来，第二次发生时一句点回第一次，听的人自己就懂了，不用解说者讲道理。

| 东西 | 默认放在哪 | 为什么 | 例子 |
|---|---|---|---|
| **主角的秘密 / 全片的谜底** | 按乐趣：坠落、博弈、注定→早交；摸黑→同步；被骗→守到底 | 乐趣决定观众站哪 | 玉面情魔开场就交"害死了父亲"；宿敌守到解码段 |
| **规则** | 讲在它第一次被用到、或第一次咬人的时候 | 提前讲是讲课，用时讲观众立刻懂 | 环形使者十五码 15 分 → 101 分；时空线索活人会死 54 分 → 87 分 |
| **世界设定** | 钩子之后，用"原来"解释观众刚看到的怪事 | 设定是答案，先有问题 | 千钧一发"原来，数百年后"；极乐空间"原来，在21世纪末期" |
| **主角的往事** | 主角需要它、最狼狈、或拿它当论据时 | 往事是给现在用的 | 少数派报告儿子 70 分；陪审员2号醉驾在陪审室说出 |
| **人物** | 闯进主角的故事、一出现就改变局面时；从主角的感知进场（一个声音、一张脸、一句"难道"） | 观众不用提前认人 | 编号17 纳莎的声音；不死劫伊利亚借"难道我是超人"进场 |
| **配角早先单独的戏** | 压成一句来历，放在他闯进来时 | 不离开主角 | 极乐空间克鲁格打飞船；时间旅行者的妻子戈麦斯撞破秘密 |
| **伏笔（要留的）** | 按乐趣标或不标 | 注定片：标得越亮越揪心；对答案片：提示是玩法；被骗片：标了就泄底 | 时间旅行者的妻子"第一个也是最关键的隐患"；时空线索"戴手套的这一幕"；宿敌母亲那句原样放过 |
| **伏笔（不留的）** | 删埋设，兑现时一个定语补出 | 收的时候自己说得清 | 超能失控"一直向往的西藏"；黑洞频率"能翻身的礼物" |
| **因果链** | 主角想通的那一刻一次讲完，原片后面才揭的环节也可以提前补 | 连锁片的快感是"原来是这样连起来的" | 黑洞频率母亲为什么在医院、那个病人就是凶手 |
| **对手的诡计** | 博弈片可以提前说破，让观众比主角先知道 | 观众站在棋盘上面 | 赎金血衣是假的（1:34 → 1:21） |
| **主角后来才说出的推理** | 提前到事发那一刻，拆成"疑点" | 让观众一起推 | 赎金第二个疑点（1:01 → 47 分） |
| **事后才揭的主角行动** | 改成先讲意图再讲结果 | 观众跟着主角的脑子走 | 时空线索激光笔 |
| **主题、片名的意思** | 结尾，等画面兑现它之后 | 开头点题是报幕 | 赛末点、破绽、环形使者结尾的三个画面 |

**预告只给方向，不给内容**："殊不知这将成为一切祸端的导火索""此刻他还不知道/自己这个快死的打工人/将掀翻这整个世界"。
单独拿出一句预告，观众应该猜不出具体发生了什么。

**产出**：信息调度表。这张表决定了下一步的顺序。

### 第 4.5 步：逐拍追问（写稿的底稿，不能省）

字幕给的是"发生了什么"。他讲的是"为什么发生、为了什么、带来了什么"。这一步就是把后面这些全推出来，写成两张表：

**表一：片子背后的发动机。** 观众到揭底才知道的那些事——谁在什么时候、为了什么、做了什么，后果是什么。
写稿的人必须先知道全部真相，才能让前面每一处"怪"都有根、揭底时每一件都能收回。
例（《异次元骇客》）：富勒为什么死前改遗嘱（料到楼上的人要借继承关机）→ 后果（简的计划落空，霍尔却成了最大赢家和头号嫌疑人）。

**表二：主角这条线的每一拍。** 每一拍四问：
1. **他想要什么**（目的）；
2. **为什么是现在、为什么这么做而不是更简单的做法**（原因，包括观众会问的"他为什么不直接……"）；
3. **结果是什么，冒出了什么新问题**（后果，它就是下一拍的动机）；
4. **这一拍里每一场对话**：说话的人为什么这时候说、想让对方怎样；听的人怎么理解、因此变成什么样。

**写的时候**：事件只当句子的由头，句子要说的是表里那几栏。
- 推进：目的 → 行动 → 撞上什么 → 结果 → 新问题（"他比谁都想知道那条消失的留言里说了什么/……果然"）；
- 意外：用"可他算漏了一件事""她哪会想到/自己随手这么一指/指的正是那封信的下落"把后果和反讽一起带出来；
- 对话：进之前写说话人的意图（"嘴上说是老人的朋友/可他真正想谈的是钱"），出来写后果（"这一句呛人的话/反倒让霍尔确定了一件事"）；
- 揭底：拿表一把前面每一处怪重新解释一遍。

**检验**：把一段里带出因果的那几行盖住，剩下的如果还能把故事讲完，这一段就是事件流水，回到表里重写。

## 第二段 · 搭骨架

### 第 5 步：挑钩子

**挑哪件事**：按乐趣（第 2 步表）。
- 坠落 → 第一次越线那一下（超能失控 55 分、天才瑞普利杀人之后）；
- 摸黑 / 被骗 → 原片开场主角撞上的第一件怪事（源代码、宿敌 13 分、升级 12 分——前面的日常可以整块扣下）；
- 规则 / 注定 → 规则和代价同时出现的那场，哪怕在 28、95 分钟（时间旅行者的妻子、少数派报告）；
- 博弈 → 最反常的一步棋（赎金 67 分）；
- 对答案 → 一个小动作或开场谜题（时空线索碰女尸的嘴唇、年鉴计划录像里的自己）；
- 连锁 → 前情一句话概括（冷血追击"窝囊一生的他……将拉上这整座城来给儿子陪葬"）；
- 规则片还有一种：**把规则改写成问观众的选择题**（环形使者"这份活你接吗……现在你还接吗"）。

**钩子可以拼**：把散在几处、讲的是同一件事的东西拼成"秘密 + 秘密被威胁的那一刻"（千钧一发：尿检 + 伪装道具 + 跳舞 + 睫毛）。

**写法**（详见 SKILL.md 第二节第 1 条）：
1. **第一句**：把这件小事接上它最大的后果，反差大到让人想"这怎么可能"。
   - "仅凭一袋他人的尿液/他就从一个底层清洁工/蜕变为万人敬仰的人上人"（千钧一发）
   - "他只是碰了一下女尸的嘴唇/不仅改写了整个城市的命运"（时空线索）
   - "明明200万就能换回儿子的命/但坐拥数亿的他却在送钱的路上反悔了"（赎金）
   - "反社会人格加超能力等于什么"（超能失控，问题式）
2. **演出来**：快节奏，一句比一句加码（"但这还不是最离谱的操作"）。
3. **转一句只给方向**："没人能想到这个白手起家的巨头有多洞悉人性/他将用一场顶级的心理博弈/来完成一次最巧妙的翻盘"。
4. **片子介绍**（较新的稿子有）：一两句导演、背景、片名的意思，放在钩子之后，后面紧跟一句真正的看点（时空线索"那么，他为何会在办案时不断产生既视感呢"）。
5. **接主角**："他叫安德鲁/他的生活简直糟透了"，或用"原来"倒回去。

**钩子那一场到原位置还要再讲一遍**，原声也可以重放（超能失控、赎金、猫鼠游戏）。第二遍观众听的是"怎么走到这一步"。

### 第 6 步：定讲述顺序

**默认骨架**（24 部里大多数）：
```
钩子 → （片子介绍）→ 倒回：主角的处境/世界设定 → 按原片顺讲到底 → 结尾（解码/解读）
```
**他不是在"重排剧情"，是在"决定开头和结尾"，中间信任原片。** 中间他动的多半是信息（第 4 步），不是场次。

**场次要动的五种情况**：
1. **原片开头太弱**：钩子从中段取，开头的东西拆散补进去（记忆裂痕两次倒叙；时间旅行者的妻子开头六次来回：28→08→02→05→14→45→64→11→28 分）。
2. **原片套了好几层框架**：拆开，按时间放回顺叙（猫鼠游戏）。
3. **同一类东西散在好几处**：攒成一块（超能失控的能力展示；时间旅行者的妻子克莱尔的三次草地按她的年龄排）。
4. **挪一场，让后面的一句台词有根**：宿敌把母亲否认"孪生兄弟"那场前挪 18 分钟，亚当见面时说"我们不是兄弟"才站得住；排练挪到对峙之后，同一句原声先当真的怒火、再揭穿是彩排。
5. **交叉剪辑拆开**：一条讲完再讲另一条，用"几分钟前""与此同时""镜头一转"接回（升级菲斯克、黑洞频率大火和酒吧、冷血追击考斯曼和瑞安、环形使者老乔找第二个孩子）。
   **放在哪一条后面**：放在触发它的那件事之后（环形使者：Cid 杀了杰西、小乔看见了，记忆才涌进老乔脑子，所以老乔那块放在杰西死之后）。

**挪不挪，三问都答"是"才挪**（SKILL.md 第三节）：补的来历一两句够吗？会不会打断主角最紧的一段？原位置有没有给后面铺东西？

**产出**：段落顺序表，每段：原片时间 / 内容 / 和原片相比挪没挪 / 为什么。

### 第 7 步：定哪里放慢、哪里一笔带过

**不定长度，不算比例，不数行数。** 他的稿子长短差得很远，那是片子决定的；同一类段落，在不同片子里长短也不一样。
看他重视哪里，不看他写了多少，看他**怎么写**：
- **放慢的写法**：一个发现接一个反应；替人物打算盘（"若站在此刻劫匪的角度……"）；把画面一句一句说出来；动作配"为了"；原声前后都有他自己的判断。
- **带过的写法**：只留结果一句（"经过反复粉身碎骨的折磨/他已经可以躲开洒叔的咖啡"）；一句"难怪"收掉一大段铺垫；压成一个定语（"一直向往的西藏"）。

**哪里放慢**——问的是：听的人此刻需要什么。
1. **规则第一次立住的地方**：后面每一段都靠它，这里没听懂，后面全跟不上（源代码第一轮，每件怪事后面都跟一句科特的反应）。
2. **主角的认知翻转**：观众是跟着人物的反应进戏的，翻转讲快了，观众只拿到一条信息，人没跟着变（少数派报告看见自己是凶手）。
3. **这部片的乐趣场**：观众来看的就是这个（升级两次"授权"的打斗、赎金棋局翻转以后两边的算盘、千钧一发每一次检测）。
4. **原片没台词的重场**：听的人看不到画面，他不说，就等于没发生。**替画面说话不等于写长**：环形使者老乔杀第一个孩子只有几行，可每一行都在补老乔心里。
5. **坠落前的最高点**：最高点越实，摔下来越疼（超能失控学会飞，他还把"最美好的一天"删了，最高点全压在这一段）。
6. **要收的伏笔，埋的那一次**：收的时候要观众记得，埋的时候就得讲到记得住（千钧一发第一次游泳、银牌）。

**哪里带过**：配角来历、解释、社会讽刺、纯抒情、过场、主角不在场的侦查；后半的灾难链每一环一句（年鉴计划）。
**检验**：把这一段压成一句结果，听的人会少知道什么、少感受到什么？说得出来，就放慢；说不出来，就带过。

**为什么不能拿数字来定**：
- 行数是写法的副产品，不是判断本身。原声多的段落行数自然多（陪审员2号法庭作证，一半是原声），却不等于他在那里多下了功夫；他替画面说话最用心的地方，可能只有几行（环形使者）。拿行数倒推"他重视哪里"，两头都会错。
- 这份工作法早先用程序把他的稿子按原片每 10 分钟数行数，再从数字里读规律。锚点一误配，就造出不存在的规律（极乐空间"60–70 分占了一半"）；就算数对了，数字也只说得出"这里写得多"，说不出为什么。照着比例写，每部片都会长成一个样子——这正是旧版技能"短句占 26%""每篇三次'此时'"犯过的错。

**他做得不好的地方**：动作戏三段一场接一场讲满（极乐空间、升级后半）。动作戏只讲"他怎么想到的"和"代价"，过程可以压。

### 第 8 步：挑原声

**原声放在四种地方**：
1. **身份和处境被打破的那一句**：*But you already died*（黑洞频率）、*you've been with us for two months*（源代码）；
2. **交锋本身就是戏**：赎金电话对骂整段、宿敌亚当结巴的长段；
3. **对手的底牌**：*This is my show / I say when it's over*、*I'm an apex predator*；
4. **主线那句**：源代码"一切都会好起来"每次出现都留。

**解释性的长对话一句原声都不留**（源代码原理那段、极乐空间几乎全转述）。
**同一句原声可以用两三次，每次意思不同**（宿敌 *did you fuck my wife*：真的怒火 → 彩排 → 对峙）。
**原片里一字不差重复的台词，是现成的回声**，留着到结尾用（时空线索那句"最重要的事"、千钧一发"如果你还感兴趣"）。

进出原声各写一句：进之前一句交代谁在对谁、为什么（"汤姆在硬气和求饶之间选择了破口大骂"），出之后一句写结果或反应（"这番话惊掉了全国人的下巴"）。**不复述原声说过的话。**

## 第三段 · 写

### 第 9 步：按段落类型写

正文的每一段都属于下面某一类。每类有他固定的几步动作（不是模板，是他的"手势"）。
**每写一段之前，先读 `body-passages.md` 里同类场面的原文，读完再写。** 只对着规则和场次表写，出来的一定是转述字幕。
不管哪一类段落，下面四样都要在：
- **画面**：看得见的动作和细节，尤其是透出心思的那个小动作（"他没有第一时间看向镜子/而是先关闭洗手间的门/深吸一口气后"）；
- **人物脑子里的话**：用人物的口气说他的算盘（"做一个失忆大师有什么不好呢"），不写"在他看来……"；
- **表态**：每两三行，对刚发生的事来一句说话人的口气（"可太简单了""像个小白一样""人家毕竟……"）；
- **动因**：这一步是上一步逼出来的，写出那根线（"按捺不住好奇的他……可此举却被老板误会成了……可老板的这番话显然更让他好奇了"）。

#### 9.1 人物入场
**先做事，再报名字；从主角的感知进场；一两句来历；立刻接他带来的变化。**
- "他叫克里斯"出现在克里斯打完那场球之后；
- "熟悉的声音让18号终止了灭口的想法/来人是 MICKY 在这船上仅存的慰藉"——声音进场 → 她是谁 → "可现在 MICKY 却要吃自己的醋"（编号17）；
- 配角一句话给出位置和来由：（冷血追击）"但哥哥也毕竟曾混过道上/所以他是考斯曼能想到的/唯一能打听到那帮派的人"。

#### 9.2 世界设定 / 规则
**用"原来"解释刚看到的怪事；只讲能做什么、不能做什么；一个比方；马上落回主角。**
- "原来，数百年后/人类掌握了基因改造的技术……但文森特不同"（千钧一发）；
- "就好像电灯关闭后仍有余晖一样/人脑在死亡后仍有8分钟的记忆轨迹"（源代码）；
- "就仿佛赛博朋克中的超梦"（时空线索）；
- 规则用到时才讲："这把短管霰弹枪在15米内精准无比/可超过这个距离就毫无杀伤力"（环形使者）。

#### 9.3 推进段（正文的主体）
**主角想要什么 → 为此做了什么 → 撞上什么 → 结果 → 冒出什么新问题。** 下一段接着这个新问题走。
- "为了搞清楚眼前的一切/他在列车中途停靠时观察四周"（目的在前）；
- "可他刚打算上去问话/就被漂亮女人打断/这才得知/那人是个总赶时间参加节目的喜剧演员"（撞上 → 结果）；
- "既然锁定绑架女人的和炸弹客是同一人/那直接盯着那个女人看不就得了"（推理 → 新行动）。
**替人物打算盘**："若站在此刻劫匪的角度/拿到钱/肖恩会死/没拿到他一时半会儿就出不了事"（赎金）；
**替观众推出规则**："那就说明眼前的男人并非引爆炸弹的人"（源代码）。

#### 9.4 交锋段（原声）
**一句进（谁对谁、处境）→ 原声 → 一句出（结果或反应）。** 见第 8 步。

#### 9.5 对话段：讲作用，不复述
**写得像不像他，这一条最要紧**（SKILL.md 〇.5 第 6 条、第二节第 9.5 条）。他几乎从不把一场对话一来一回地讲出来，一场对话被换成三样东西：
1. **说话的人想要什么**：对话的内容当成"条件""局面"摆到主角面前，说话的人退到后面。
   赎金绑匪的邮件："这个绑匪的要求倒不过分/200万现金不连号/且不许做记号/不许通知警方或联邦调查局/更不准通知媒体/否则他就撕票"——没有一个"绑匪说"。
2. **听的人怎么算、什么反应**：这是重头。
   记忆裂痕吉米开出三年的条件，原声来回之后只接一句"言之有理/没准3年后他就能提前退休了"，直接落到迈克心里那本账上；
   天才瑞普利船王问他认不认识自己儿子，"早想攀附权贵的他并未否认"。
3. **这场对话的结果**："而这也让富豪深信/他和自己的宝贝儿子很是相熟"；"他三言两语就俘获了女人的芳心"。

对话本身就是戏的，交给原声（9.4），解说只写开口前的处境和说完后的分量。
信息非交代不可时，用"从……口中得知""在……的介绍下"一行带过，下一句马上转到主角的判断上："探员朗尼解释/没准对方是怕事闹太大/而汤姆却认为这或许是报复/毕竟……"。
他偶尔也会把一段劝说压着讲，可落点一定在听的人身上：朗尼劝汤姆收回悬赏、保证替他保密，最后一行是"汤姆听出了这温柔的威胁"。把一段好意读成威胁，这一段才有价值。

**最容易犯的错**：把"说"换成"坦言/透露/据他所说/劝/问/表示/回答"，以为就不算转述了。句子换了动词，听的人仍然在听别人聊天。
判断不在用哪个动词，而在这一行讲的是对话的**内容**，还是对话的**作用**。改前改后（《异次元骇客》）：

| 转述对话（内容） | 讲作用 |
|---|---|
| 据他所说/那晚老头在吧台等了好一会儿/等来的正是霍尔/两人一起离开了酒吧/第二天老头就上了讣告/不过他没打算报警/他要的是一笔七位数的封口费 | 这个陌生男人一开口就让霍尔后背发凉/老头遇害那晚/他就在那家酒吧的吧台后面/亲眼看着霍尔把老头接走/可他压根没打算报警/在他眼里/这分明是一棵送上门的摇钱树 |
| 他坦言自己想不起那一晚/……简却并没有追问他到底有没有杀人/只劝他趁早别再碰那台机器 | 奇怪的是/听完他的遭遇/简最在意的不是他有没有杀人/而是那台机器/她只想让霍尔离它越远越好 |
| 于是他问格里森/你是不是时不时就会昏过去/是不是醒来后根本不知道自己在哪…… | 他没再提富勒/而是一句话就戳中了格里森藏了一个月的心病 |
| 在简看来/霍尔是有灵魂的/毕竟这个世界从设计之初/就注定没人能发现真相 | 简想拿这番话安慰他/可落在霍尔耳朵里/只让他更绝望 → 原声 |
| 面对简的质问/问他为什么要杀那些人时/他给出的理由却轻得可怕 | 这个在下面杀人如麻的丈夫/连个像样的理由都懒得编 → 原声 *Because it was fun.* |

**写完检查**：把所有在讲"谁对谁讲了什么"的行都找出来（"说"，也包括"坦言/透露/据他所说/劝/问/表示/解释/回答/告诉/追问"），每一处问：
- 这场对话本身是戏吗？是，交给原声，解说只写开口前和说完后；
- 不是戏，它在这里起什么作用？写出局面（说话的人要什么）、算盘（听的人怎么想、怎么反应）、结果；
- 三样都写不出来，说明这场对话推不动主角：删掉，或者压成一句结果。

#### 9.6 认知翻转 / 揭底段
**放慢；落一个事实；接人物反应；补"原来"；然后一口气倒回去，拿答案把前面每一件怪事重新解释一遍。**
写之前先把前面铺过的怪事全列出来（谁的什么反应不对劲、哪个证据说不通、谁说过一句怪话），揭底时逐件收。漏收一件，听的人就会觉得"那之前那个呢"。
- "唐纳德正是他父亲的名字/这一瞬间/大量的记忆涌进他的脑海"（源代码）；
- "控制那台 AI 汽车发生侧翻的是他/指使菲斯克废掉格雷脊椎的也是他/接着他再让艾伦出面把自己送给格雷/所以最初向格雷夫妻展示丙的并非艾伦/而是那枚芯片本身"（升级，一次收三处）；
- 对答案片："难怪当初没有打斗痕迹/因为那些血迹竟都来自他自己"（时空线索）。

#### 9.7 群戏 / 双线切换段
**每一切都告诉观众为什么到这里来：这是谁的一步棋、哪件事的后果。**
- "镜头一转，来到考斯曼这边"；
- "维京这小子哪能想到/自己得罪的不过是一个小人物父亲"；"可他不知道这一枪又捅了马蜂窝"——用"哪能想到/却不知/又"拴住链条（冷血追击）；
- "但也就在几分钟前/已经有两人见证了洗手间内的惨状"（升级，主角不知道的危险）。

#### 9.8 无台词重场 / 蒙太奇
**一个画面一句，一句比一句加码；替人物补心里；最后一句落在结果上。**
- "他突然发现自己的手指缺了一根/三秒后又缺失了第二根/就连他的鼻子也瞬间不翼而飞……很快他失去了右脚/接着是左腿"（环形使者）；
- "起初他用那些钱继续着纸醉金迷的生活/但6年过去/他的钱已然见底/终于，在第10年的时候……"（环形使者三十年）；
- "曾经四肢健全的他/靠着自认为的拼尽全力/拿下了那枚奥运会银牌/而这一次……靠着双手的力量豁出一切"（千钧一发，把前面埋的银牌收进画面）。

#### 9.9 动作段
**只讲"他怎么想到的"、局面怎么翻、代价；过程压。**
- "他把室内的电线拆了下来/然后把里面的铜丝揪出来/分别绑在铁网和门把手上/再把那些茶水倒在锯门口半米处"（黑洞频率，"怎么想到的"就是戏）；
- "给你台阶你不下/那就别怪我心狠手辣"（升级，俗语给节奏）。

#### 9.10 解码 / 解读段（被骗、对答案、留白多的片）
**跳出来说一句"接下来让凡凡帮你们捋一捋"；按线索一条条收；每条落在具体的东西上；给原片的留白一个答案；"我个人认为"。**
- 宿敌：钥匙 → 车祸 → 从不同框 → 蓝莓（回调两句正文跳过的原声）→ 蜘蛛；
- 时空线索：A/B/C/D 四个时空、"凡凡猜想失败的原因是/他把克莱尔留在了家中"、卡罗尔也有既视感。

### 第 10 步：衔接

**他的衔接骨架是因果，不是时间。** 读他的稿子，段与段之间接得最多的是"因为/所以/为了/既然/毕竟/原来/果然/这才"，"然后/第二天"反而少。
为什么：只用耳朵听的人没法往回翻，每一段开头都得先让他知道"为什么到这儿来"——是上一件事的后果，是人物为了某个目的，还是一个没料到的转折。用时间接，他只知道"又过了一会儿"，不知道这一段和前面是什么关系。
这不是要凑连接词，有的段落一个连接词都没有，靠"可他刚……就……"这样的句子本身带出因果。**段与段之间问自己：这一段为什么接在上一段后面？答案写成第一句。**

按功能分的衔接（左边是功能，右边是他常用的说法，括号里是用的场合）：

| 功能 | 说法 |
|---|---|
| 因果、目的 | 为了……/既然……那……/毕竟……/所以……/因为……/这让…… |
| 转折、意外 | 可就在……时/可他刚……就……/本以为……/但没想到/谁能想到/却不知/殊不知/哪知道 |
| 发现、应验 | 果然/原来/这才/难怪/也就是说/显然 |
| 加码 | 更要命的是/更糟的是/更离谱的是/甚至/就连/但这还不是最离谱的 |
| 时间（钩子回拨、接回） | 几天前/数日前/隔天/天亮后/数日后/几分钟前/也就在此刻 |
| 切换视角 | 镜头一转/与此同时/而……这边/同时在……的这条时间线 |
| 主角不知道的事 | 他不知道的是/此刻的他还不知道/殊不知 |
| 小结局面 | 至此/这一番操作/眼下/好在 |
| 预告（只给方向） | 殊不知这将成为……的导火索/他怎会知道/此刻他还不知道 |
| 回扣（对答案片） | 大家想起……了吗/所以各位想起起初那段剧情了吗/难怪 |

**三条规矩**：
1. **转场句里要有一个人在做一件具体的事**（"隔天，斯坦来到法官家中"），不用一句概括宣布"接下来会怎样"。概括只放在事情讲完之后（"至此……"）。
2. **"殊不知/他不知道"这类预告，一部片里要有理由才用**：坠落片、连锁片用得多；摸黑片、被骗片几乎不用（会泄底）。
3. **讲完往事要接回来**："接下来就发生了故事开头的一幕"；钩子提到前面的场面，原位置要接上（"画面一转/再次回到了乔进行闭环的那一刻"）。

### 第 11 步：措辞

**先过 SKILL.md 〇.7 的五个根子**：画面、人物脑子里的话、表态、对话让台词自己响、道理讲透。下面是句子层面的事。

**一行一个完整的小句，靠连接词往前推。** 为什么：口播是一口气一口气念的，听的人每听完一行，就该拿到一件能单独听懂的事（谁、干了什么、为什么）。
切成三五个字一行，意思要等好几行才拼完整，耳朵跟不住；一行塞进两三件事，又来不及消化。所以一行有多长，看的是这一句的意思完不完整，不是字数。
行首常常是人物或转折（"他""可""却""而"）：**主语清楚**，听的人知道这句在说谁；**转折推进**，知道局面往哪拐。
短行只用来顿一下："说干就干""这一刻""几天后"。

**他的声音长在这几处**：
1. **定语 + 人名做主语**，一个短语交代人物此刻的状态：
   "慌不择路的瑞普利""浑然不知的维京""智商在线的吉米""从没干过偷鸡摸狗之事的格雷""满腹疑问的他"。
2. **说话人的口气**：可太……了/还真……/哪会是……/人家毕竟……/这下……/不愧是……/可别……
   "对一个玩转机器的修理工来说/想破开一道锁可太简单了"；"人家毕竟是打家劫舍的劫匪……格雷哪会是他的对手"。
3. **人物反应**：他懵了/愣住了/如坠冰窟/汗毛直立/更让他难以置信的是。发现之后必接一句反应。
4. **替观众推理**："说明对方的肢体是经过改造的/仅凭这一点就能缩小调查范围"；"要知道……"补背景。
5. **标签**：每部片给主角、对手各一个，贯穿全篇（"抠门哥""披着警服的狼""拖油瓶杀手""胆小如鼠的17号/狠角色18号""玻璃人"）。
6. **成语、俗语、网络词**：如出一辙、东窗事发、三下五除二、给你台阶你不下、光荣的进化、破防、嘴遁、deep sick。不堆，但不避。
7. **比方用观众身边的东西**：超梦、时间胶囊、"练个小号"、"当网友"、看病难看病贵。
8. **调门跟着片子**：黑色喜剧讲冷笑话（冷血追击"冰河里的鱼儿会替他完成剩下的工序"，之后每杀一个都回到这条线）；博弈片满篇"赌""棋子"；正剧几乎不开玩笑。
9. **越离谱的事说得越平**："脸上并没有胜利者的表情/仿佛只有对优质独家素材的渴望"（夜行者）。

**凡凡自己出场**，一部片里一两处，有理由才出：
- 点名"这一幕要记住"（千钧一发"这一幕也成为了贯穿电影的经典一幕"）；
- 说出自己的情绪（"这份反转是最令凡凡震惊兴奋的"）；
- 跳出来进解码（"这让凡凡有些无语/因为发现直到临近电影结束/导演依然在误导我们"）；
- 对答案片的提示（"凡凡再次提示各位"）。
**不要在故事中途跳出来评论片子的信息安排、提前下主题结论。**

**不要写的**：三五个字一行的碎句；格言式对仗（结尾那一句例外）；收尾式往下坠的短句（"倒下的是阿什顿"）；"故事要从……说起"；"他说/她说/坦言/透露/表示"式转述；只有决定没有理由（"他决定再下去一次"）。
**对话**：他几乎不复述对话。写完把所有"谁对谁讲了什么"的行挑出来，按第 9.5 步的检查过一遍；换一个动词（坦言、透露、据他所说）不算改。

### 第 12 步：结尾与自检

**结尾**（SKILL.md 第二节第 11 条）：
- 先收故事：主线那个词或那件东西在结尾回来（编号17"他不是多少号/他就是 Mickey"；冷血追击"有些路清了/明天依然会积雪"——来自片头致辞里的"路"）；
- 解码或解读（被骗、对答案、留白多的片）；
- 道理：**从这部片里长出来，最好用这部片自己的比喻**（时间旅行者的妻子：图书管理员 → "一本被剧透的书"；超能失控：蜘蛛侠的话反过来"能力越大，黑化越重"）；
- 原片的最后一句、最后的旁白可以直接用来收（千钧一发、超能失控、极乐空间）；
- 签收："感谢观看本期《X》/我是凡凡/我们下期再见"。
**两个坑**：议题叠太多（源代码记忆 + 军方 + AI）；道理和正文拧着（不死劫）。

**自检**：SKILL.md 第七节的问题逐条过，外加这几问——
0. **是不是在转述字幕**：随手挑一段，问"只看字幕能不能写出来"。能，就是缺画面、缺人物脑子里的话、缺表态。再拿 `body-passages.md` 里同类那段并排读一遍，哪里不如他，就改哪里。
1. **删**：删掉清单里每一场，过了第 3 步的四问吗？有没有后面的台词因此失去根？
2. **加**：每一处加的东西（标签、心理、推理、比方、凡凡出场）是在帮观众听懂、跟上、觉得好玩，还是在显示我的结构？
3. **顺序**：每一处挪动说得出为什么吗？交叉剪辑拆开了吗？讲完往事接回来了吗？
4. **轻重**：放慢的是不是规则、认知翻转、乐趣场、无台词重场？放慢的地方，是真在写反应、算盘、画面，还是只是字多？有没有一条旁线写得比乐趣场还细？
5. **对话**：有没有哪一场对话被一来一回地讲了出来（包括换成"坦言/透露/据他所说/劝/问"的）？每一场写的是作用（局面、算盘、结果），还是内容？概括的地方听得出解说者的态度吗？该让台词自己响的地方，是不是被我压成了摘要？
7. **道理**：每一步的动因写了吗？线索是怎么来的，有没有跳过一环？观众会问的"他为什么不直接……"答了吗？揭底收回了前面哪几件怪事，哪件没收？
6. **措辞**：随手挑一段读出声，有没有碎句、对仗、"他说她说"？每一段的第一句，说得出它为什么接在上一段后面吗？
