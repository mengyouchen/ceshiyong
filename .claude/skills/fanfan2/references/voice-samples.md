# 原文片段（已校正）

从 25 篇里挑出来的段落，每段对应 SKILL.md 里的一个做法。
人名和错字已按剧情改正；英文原声识别成乱码的地方，用 `[原声：……]` 写出那一处是谁在说什么。
**写稿前把这些读一遍。** 语气要从原文里找，规则写不出来。
但别照抄句式：这些是"他在这部片里这么做"，换一部片要重新想。

---

## 1. 钩子：把世界规则变成问观众的问题（《环形使者》开头）

```
如果杀掉30年后的你
可以得到16根金条
这份活你接吗
需要注意的是
30年后
你也会被这部单向时光机送回30年前
再被30年前的自己杀死
现在你还接吗
```

第一问给诱惑，第二问加上代价。观众一下就懂了这个世界最残忍的地方，而规则本身就是钩子。

## 2. 钩子：先把结局压给观众（《天才雷普利》开头）

```
如何三步速成富二代
……
他方才杀的是他最好的朋友
也是首富最宝贝的独子
接着他改头换面
直接假冒对方的身份去取钱
……
就连那人的未婚妻
他也想据为己有
他叫雷普利
数日前，在一场权贵的聚会上
他身上借来的这件校服改写了他的命运
```

观众先知道他会杀人、会冒名，前半段每一次"被看不起"就都成了倒计时。

## 3. 钩子：自己给一场沉默的戏搭个框（《破绽》开头，节选）

```
他身价万亿
却亲眼目睹深爱的妻子红杏出墙
可他却并未声张
只是在瞬间就为她准备了三个问题
关乎她是否能活命的问题
……
她强装镇定
却不知道自己已经答错了第二题
她在突发状况下表露出的第一反应
是丈夫心中早已笃定的错误答案
……
三题全错
```

原片里只是看见、回家、拥抱、开枪。"三个问题"是他加的，一段没有台词的戏就有了倒计时。

## 4. 讲意图：每个动作都说"为了什么"（《终局名单》第1期，踩点）

```
天亮后，李斯伪装成租客
在对霍华德进行审问之前
他必须来到对方的公寓进行踩点
……
接着在女人介绍房间的空档
他拍下了这里统一使用的门锁的品牌和样式
这是为了保证在最快的时间内撬开那道锁
以便撬锁发出的噪音不会持续太久
导致被对方察觉
……
离开时又在门的内侧喷上润滑剂
这是为了夜间潜入时更好地减少噪音
```

一个兵王厉害在哪，是从这些"为了"里听出来的，不是靠形容词。

## 5. 骗术：先演效果，再揭方法（《玉面情魔》，警长那场）

```
他径直冲到那名警长面前
开始了他的第一场表演
[原声：斯坦叫出警长的全名 Jeremiah]
斯坦精准无误的说出了警长的名字
要知道作为新上任警长的他
连有些手下都不知道他的全名
但这还只是开始
他把警长带到一边
不仅说出对方幼时患有恶疾一事
还表示他的身上带有一件至亲的遗物
……
而他能洞悉警长内心的秘诀
是因为刚刚撞到一名警员后
从那张搜查令上看到了警长的全名
又在戏台下看到警长的右鞋中垫了增高鞋垫
一定是小时候得过小儿麻痹症之类的病
```

观众先和警长一起被唬住，再和斯坦一起看懂。两次快感。

## 6. 用主角自己的世界观去讲他（《夜行者》，散落各处）

```
他像一个专业的求职者般
向对方推销自己
表示跟着对方干
即便有实习期也没有关系
……
而这第一桶金对路易来说不是关键
……
他把新闻剪辑出来并记录
这是他的第一个作品
但进步需要学习
……
通过互联网自学了资本主义生存法则的他
深知，通过良好的沟通才能解决问题
……
就迎来了他的第一次低谷
这也将成为他更加癫狂的契机
……
他选择不再做一个犯罪记录者
……
他选择做一个犯罪的制造者
```

讲成一部职场升级史，越像励志故事越让人发冷。语气本身就是解读。

## 7. 主线词：把片子的核心概念变成反复响起的词（《赛末点》）

```
他是个秉承运气至上的野心家
……
但运气之神是眷顾他的
……
看来气运之神还是眷顾他的
……
他再一次被气运之神眷顾
……
即便他运气不错
但同时也得益于他的冷静
……
而她在临走时匆忙扔掉的那最后一枚戒指
也将决定他的未来
这枚戒指的落点同样也是运气
……
而这个暂时的结论也是克里斯的运气
```

结尾一句"运气才是唯一的、冷酷的上帝"之所以站得住，是因为前面已经响了七八次。

## 8. 替观众读出台词背后的东西（《天才雷普利》，玛吉安慰他）

```
[原声：玛吉说迪基像太阳，照着你的时候很温暖，转头就忘了你；
每当他认识新的人，就……]
雷普利听出来了
玛吉安慰的并不是他
而是她自己
```

## 9. 在爽片里插一处代价（《终局名单》第2期，宝拉）

```
[原声：宝拉对李斯说，明天之后如果你还活着，请不要再回来；
你可以为复仇去死，但不该把朋友拖进来]
李斯沉默
宝拉让他别再回来
不仅是地理上的驱逐
更是情感上的割席
但李斯无法反驳
因为仇恨只能成为循环
或许马可也将因他而死
```

这一处放在突袭营地、开膛处决之前。杀戮前先让观众看见代价。

## 10. 冷描写：最可怕的事用最平的话（《夜行者》，拍前辈）

```
路易不断调整角度
拍摄着重伤的前辈
生怕漏过任何一个细节
而那人能做的只能是目不转睛的盯着他
此刻路易的脸上并没有胜利者的表情
仿佛只有对优质独家素材的渴望
```

## 11. 给坏人说他自己的理，再判一句（《终局名单》第4期，哈特利）

```
哈特利认为
当 RD4895 问世后
这12个人的性命就会显得微不足道
她自认为这是在做好事
但她并没有经过那些人的同意
权力不是她藐视人权的武器
```

## 12. 进故事前，先给观众一个观看的框（《陪审员2号》）

```
但在进入故事之前
看完原片的凡凡想请各位注意
他是男主角
但不是主角
主角是庭审中所有角色所映射出的我们
它没有悬疑片所谓的反转
但直到最后我才发现
整个故事本身就是反转
……
请记住这个顺手关灯的动作
他并非无意
```

## 13. 戏剧反讽，替观众笑出来（《陪审员2号》，陪审室）

```
12个人还未进行讨论
```

## 14. 荒谬的规则，用同一句话讲两遍（《少数派报告》）

```
也就是说
当三位先知同时预知后
如果预测画面一致
将生成一份确定性报告并出警逮捕
最终结果是预言从未出错
但如果预测画面不一致
将额外生成一份少数派报告
接着高层利用权限销毁少数报告
按多数报告执行
最终的结果依然是预言从未出错
而这代表着他们一定冤枉过好人
```

## 15. 前面讲的往事，马上在动作里兑现（《少数派报告》）

```
他和儿子西恩在比赛憋气的时候
可当他潜入水下后没多久
就发现儿子的手表掉入了水中
等他回到水面上时
儿子早已不见了踪影
……
（几分钟后，机器蜘蛛搜查，他躲进冰水浴缸）
在水下坚持几分钟
对擅长憋气的约翰来说并不困难
```

## 16. 剧集一期的结尾：不升华，留悬念（《混沌少年时》第1期）

```
这一刻
原本完好的两个家庭同时坠入深渊
父亲一时间从愕然变为不解
又从愤怒变成崩溃
即便儿子叫了自己好几声
他仍然无从作答
此刻的杰米是如此的陌生
但事实又真的如此吗
```

《终局名单》第2期的结尾是一个舞台比喻："接下来的舞台/李斯将邀请那位霍恩集团的大老板/和他共同出演"。

## 17. 电影结尾：换一个主角来看（《猫鼠游戏》）

```
这部电影也被很多人讲过
可凡凡发现
大多讲述的侧重点在天才弗兰克的犯罪传奇上
这确实是电影最大的看点
但在影片深意下
真正的主角其实是那只猫
与卡尔恰恰相反
弗兰克的生父是他悲剧的起点
是他犯罪哲学的启蒙者
但卡尔这个陌生人的追捕
却从一开始的职业任务
逐渐转变为一种带有父爱色彩的拯救
……
再迷失的罪人
只要能被真诚的看见和理解
就永远有找回真实、重归生活的可能
我是凡凡
我们下期再见
```

这个看法在正文里早就铺好了：圣诞夜的电话、狱中送漫画、卡尔在上司面前"我儿子还有两下子"的表情。结尾只是说破。

## 18. 电影结尾：拆片名（《破绽》）

```
而后他又钻了法律的破绽

他对威利的这番提示
最终让自己也露出了破绽
```
