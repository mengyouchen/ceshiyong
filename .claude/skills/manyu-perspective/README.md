# 漫语 · 悬疑解说写作操作系统

影视解说博主「漫语」的写稿与选题思维框架，从 14 篇完整解说口播稿（悬疑惊悚/灵异题材，约 9.5 万字）蒸馏而成。

## 这个 Skill 能做什么

装上之后，直接说「用漫语的风格写…」「这片漫语会怎么开头」「帮我把这段改成漫语式」就会激活。覆盖七类请求：

| 你说 | 它做 |
|------|------|
| 「这片漫语会选吗，打个分」 | 按选题三门槛打分，给会选/不选结论与线路判定 |
| 「漫语式切入，从哪儿切」 | 找最抓人的一幕定冷开场，判断落点定收尾 |
| 「写一篇漫语式解说稿」 | 按五段式骨架出完整可口播稿 |
| 「给我个漫语式开头/结尾」 | 套冷开场四式或双轨结尾模板 |
| 「这段够不够漫语味，帮我改」 | 逐条 DNA 诊断 + 给改后全文 |
| 「把我的稿子改成漫语风格」 | 迁手法不迁身份，**保留你自己的署名** |
| 聊创作观、选片哲学 | 用 5 个心智模型作答 |

## 核心内容

- **5 个心智模型**：钩子前置名片后置 / 惊悚外壳人心内核 / 微悬念节奏引擎 / 陪看人设 / 平台生存语言学
- **13 条决策启发式**：选题三门槛、结构五条、表达三条
- **6 条生成手册**：句子怎么从剧情原料长出来（跟着镜头写、信息泄露、观众代言、揭底留半拍等）
- **冷开场四式 + 三条下刀规则**、双轨结尾模板、平台生存词汇表、节奏硬指标

## 安装

本 Skill 遵循 Agent Skills 标准，可在任意兼容 runtime 使用。

- **claude.ai**：设置 → Skills → 上传本压缩包
- **命令行 / IDE 类 agent**：解压后放进 skills 目录（项目级 `.claude/skills/` 或用户级 `~/.claude/skills/`），保持 `manyu-perspective/SKILL.md` 的目录结构
- **其他 runtime**：解压后放入该 runtime 的 skills 目录即可；SKILL.md 为标准 frontmatter 格式

## 请先读一下边界

- 语料 **100% 是悬疑惊悚/灵异题材**（美剧为主，含俄剧、比利时剧）。喜剧、纯爱情、纪录片、华语剧属**无样本推断**，可信度低。
- 只覆盖**文案/选题/结构思维**，不覆盖配音、剪辑、画面、BGM——原始视频未纳入调研。
- 「生成手册」是对语料的细读反推，**不是博主本人自述的方法论**。
- 这是**基于公开作品的风格分析**，非本人观点，也不代表本人。语料原文不随本包分发；用它做二创请自行遵守平台规则与著作权规范。

完整局限见 SKILL.md 的「诚实边界」章节，蒸馏过程见 `references/research/01-corpus-analysis.md`。
