## 3. 钩子模板（六式）＋填空公式

> 说明：**冷开场钩子**＝报名之前的诱饵段（纯内容、无人称）；
> **本期承诺**＝紧挨报名前后的"我这期要给你什么"（承诺句可在报名前也可在报名后，见 §3.7）。

### 第一式｜数字砸脸（震撼统计／票房／评分／悬赏）
**公式**：`[反常识数字]+[被数字修饰的荒谬/惨烈对象] → [该数字的规模换算或人群扩展] → [一句道德或命运判词]`

- C：「70万悬赏一个垃圾桶 / 理发师马哈拉贾的疯癫报案 / 背后藏着一场血腥复仇」
- A：「偷婴儿吃冰块求生 / 全球1.2亿孩子像他一样活着 / 无国籍被买卖 / 垃圾堆长大 / 生而不养，何以为家」
- D：「豆瓣68万人评6.5分 / 无数人吐槽烂剧情」

**可套用填空**：
```
{数字}{单位}，{只/竟然只}换来一个{荒谬小物/一句话}。
{主角身份}的{反常举动}，背后藏着一场{血腥复仇/天大骗局}。
全球{数字}个{人群}正像他一样活着——{惨状1}、{惨状2}、{惨状3}。
```

### 第二式｜倒计时换算（时间压迫）
**公式**：`[时间量]，是[日常小事1]的时间 / 是[日常小事2]的时间 / 是[日常小事3] → 但这也是[主角]仅有的[生死窗口] → 因为[时间]之后，[彻底不可挽回的后果]`

- B：「10分钟，是你等来两班地铁的时间 / 是水壶把冷水烧到沸腾 / 是孩子们课间的短暂休息 / 但这也是蛟龙小队仅有的人质解救窗口 / 因为10分钟之后……中国海军将彻底无法跟进」
- C（微型变体，把时间换成"位置"）：「最后一幕的犯罪细节中，还隐藏着细节解读，让人细思极恐」——用"最后一幕"制造"看到最后才算数"的时间压迫。

**可套用填空**：
```
{N}分钟，是{日常小事A}的时间，是{日常小事B}的时间，是{日常小事C}。
但这也是{主角/小队}仅有的{窗口名}。
因为{N}分钟之后，一旦{触发条件}，{主体}将彻底{无法挽回的结果}。
```

### 第三式｜口碑逆转（复述差评→一句反问翻案）
**公式**：`[平台+人数+评分] → [复述最毒的三条差评原话] → 「事实真是这样吗」 → [一个用差评解释不通的悖论事实]`

- D：「豆瓣68万人评6.5分 / 无数人吐槽烂剧情 / 在电影院坐牢 / 只有特效好 / 其他一塌糊涂 / **事实真是这样吗** / 为什么这样的电影会在国庆档竟然出第二部」
- F（同机制，把"差评"换成"集体误读"）：「这也就导致了我们实际上**从未真正全面理解**禁闭岛这部作品」

**可套用填空**：
```
{平台}{人数}人评{分数}。
无数人吐槽{差评1}、{差评2}、{差评3}。
事实真是这样吗？
为什么这样的{作品}，会{与差评矛盾的事实：出续集/拿奖/被反复重映}？
```

### 第四式｜独家知情（"只有我知道"／"很多观众不知道"）
**公式**：`[所有人的错误反应] → 「只有我知道」／「很多观众不知道」 → [一个具体器物/细节] → [它将撕开的宏大真相]`

- C：「当警局所有人嘲笑他时 / **只有我知道** / 这个父亲手里的剃须刀 / 即将割开印度最黑暗的真相」
- F：「**很多观众不知道**马丁·斯科塞斯，还有原著作者丹尼斯，在改编禁闭岛的时候隐去了一部分原作中相当核心并且精彩的推理部分」

**可套用填空**：
```
当{所有人/全场/全网}都在{嘲笑/误解/忽略}他时，只有我知道——
这个{身份}手里的{具体器物}，即将{动词}开{国家/时代/人性}最黑暗的真相。
```
```
很多观众不知道，{导演/原著作者}在改编{作品}的时候，隐去了{被删内容}。
```

### 第五式｜残缺文本（原著/删减/失传 → 我给你补全）
**公式**：`[被删/被隐去的具体内容] → [它为什么被删：篇幅+剧透双重顾虑] → [因此我们从未真正读懂它] → [四连悬念清单] → [解密游戏邀请]`

- F：完整范例，见 §1 F 篇第 1–26 行。
- D（弱变体）：「在二刷三刷电影、且阅读完原著后，图图有一些不一样的观感与解读」——用"读过原著"当权威凭证。

**可套用填空**：

### 3.7 本期承诺（报名前后的"我给你什么"）——与钩子**必须分开**
承诺句的四种形态，全部以第一人称/第三人称"图图"出现，且**紧贴自报家门**（前 3 行或后 5 行内）：

| 形态 | 语料实例 | 位置 |
|---|---|---|
| ① 隐藏细节承诺 | 「最后一幕的犯罪细节中，还隐藏着细节解读，让人细思极恐」 | C 8–10（**报名前**） |
| ② 全新解读承诺 | 「图图有一些不一样的观感与解读」／「我想让更多的人看到全新的解读」 | D 11（报名替代位）、E 10 |
| ③ 解密游戏邀请＋反常规结构预告 | 「我更希望今天兔宝们，把这期视频当成一个解密游戏 / 我们会彻底的挖掘禁闭岛背后的全部真相 / 所以今天图图不想从影片的开始切入故事 / 我们先回到1953年的美国」 | F 24–29（**报名前**） |
| ④ 工作量背书 | 「本期视频耗时一个月，爆肝三万字，查阅了无数资料」 | F 31–32（**报名后**） |
| ⑤ 免责声明（承诺的收口） | 「但图图并不想改变任何人的想法 / 我们开始吧」 | D 14–15 |
| ⑥ 动机说明（公益向） | 「因为收到了儿童公益组织的邀请 / 图图也想为儿童公益组织出一份力 / 所以很高兴能够做这一期视频」 | A 17–19（**报名后**） |

**规律**：
- 「翻案／争议片」（D）承诺后面**必须跟免责声明**，先立场后免责，防杠。
- 「长稿／爆肝片」（F）承诺后面**必须跟工作量背书**，工作量背书又是恰饭的接口（见 §6）。
- 承诺句从不用"今天带大家看一部……"这种流水开场，一律是"你们漏了什么 / 我补了什么"。

### 5.3 三段式核实结论

**结构确认：结尾是固定三段式，顺序 100% 固定，不可调换。**

```
【第一段 · 互动邀请】 →  【第二段 · 署名口号】 →  【第三段 · 预告/不见不散】
    （评论区/三连）        （不善言辞但能说会道，        （下期与你不见不散）
                            拒绝影视解说快餐化）
```

| 篇 | 第一段（互动） | 第二段（署名） | 第三段（预告） | 顺序 |
|---|---|---|---|---|
| A | 「求求给个三连 / 让视频推出去吧 / 希望世界和平」 | ✅ 完整 | ✅「下期与你不见不散」 | 正序 |
| C | 「欢迎各位朋友在评论区留下你对因果报应的困惑 / 我看到了会在摸鱼时回复」 | ✅ 完整 | ✅「我有一个朋友说，下期不见不散」 | 正序 |
| D | 「有没有些许不一样的看法呢 / 欢迎评论区留言」 | ✅ 完整 | ✅「下期与你不见不散」（＋前置具体预告"等到国庆图图会第一时间去看第二部出个影评"） | 正序 |
| F | 「希望大家能够喜欢 / 图图味电影解读」 | ✅ 完整 | ✅「下期与你不见不散」（＋恰饭尾） | 正序 |
| B | ❌ | ❌ | ❌ | **全缺** |
| E | ❌ | ❌ | ❌ | **全缺** |

**第一段（互动）内部还有一个固定前缀槽**，三选一：
- 「以上就是本期节目的所有内容啦」（C，最正式）
- 「希望大家能够喜欢」（F）／「希望大家能喜欢这次的过度解读」（C）
- 情绪收束句：「每次看完都有不一样的感受」（A）

**第三段（预告）的两种强度**：
- 弱预告（默认）：直接「下期与你不见不散」。
- 强预告（有明确下期选题时）：先说清下期拍什么，再接不见不散 —— D 篇「所以等到国庆啊，图图会第一时间去看《刺杀小说家2》出个影评 …… 下期与你不见不散」。

**"我有一个朋友说"是图图的贯穿性口头梗**，不只在结尾：
B58「我一个学导演的朋友告诉我」、E39「我一个跑职业马拉松的朋友告诉我」、C1453「我有一个朋友说下期不见不散」。
→ 生成时可作为**引入外部权威/自嘲**的通用句式：`我一个{职业}的朋友告诉我，{专业判断}。`

### 5.4 例外分析：B 与 E 为什么没有结尾套语

| 篇 | 现象 | 判断 |
|---|---|---|
| **B《红海行动》** | 既无自报家门（开头），也无结尾三段式；全篇 755 行，是 6 篇里最短的（不足平均值的一半）。末尾停在原片原声「注意，我是中国海军 / 你即将进入中国领海 / 请立即离开 …… attention, this is chinese navy…」 | **高度疑似语料截断**（头尾双缺 ＋ 体量异常）。不应据此推断"图图有时不报名字"。生成时**不要**模仿 B 的无头无尾。 |
| **E《沉默的羔羊》** | 开头**有**三件套（第 14 行"先赞后看，腰缠万贯，爱您"），说明开场完整；结尾停在汉尼拔电话原声「Where are you doctor lecter…but i'm having an old friend for d[inner]」＋ASR 残句"打出来针" | **更可能是有意的"原声留白"**：影史名台词收尾，图图闭嘴不抢话。但末行 ASR 残缺，不能 100% 排除截断。 |

**可用规律（中等置信度）**：
> 当影片自带**影史级收尾台词**（汉尼拔的"老朋友晚餐"、红海的"我是中国海军"）时，
> 图图倾向于**直接留原片英文/原声，不做解说、不加署名口号**，让名台词自己落幕。
> 其余情况（A/C/D/F，4/4）一律走完整三段式。

## 6. 商业口播（恰饭）与公益植入的位置规律

| 篇 | 类型 | 位置 | 缝合手法 |
|---|---|---|---|

**规律五条**：
1. **恰饭永远不打断署名口号**。F 篇的结尾恰饭放在「下期与你不见不散」**之后**，等于片尾彩蛋——正片先干净收束，广告另起一段。

5. **恰饭结束后不做任何过渡**，下一句立刻回到剧情原句，靠硬切把观众拉回。公益植入例外，会补一句「好了，言归正传」。

### 7.2 结构定律

**图图标题 ＝ 【前舱：数字＋感叹号】＋【后舱：揭秘动词＋承诺】**，中间必有 `！` 断开。6/6 命中。

- **感叹号强制**：6/6 篇标题前半段以 `！` 结束，感叹号是"前舱/后舱"的分隔符。
- **数字强制**：6/6 篇含数字，且数字分三类：
  - **惨烈型数字**（年龄、人数）：11岁、12岁 —— 用于苦难片
  - **权威型数字**（票房、评分、人数）：36亿 —— 用于商业大片
  - **工作量型数字**（天数、字数、刷数）：爆肝30天3万字、三刷、200[…] —— 用于长篇深扒
  - **密度型数字**：每分钟 —— 用于经典片
- **揭秘动词词库（后舱必用其一）**：揭穿（C、E，2 次，最高频）／披露（F）／深扒（D）／全新解读（C）／隐藏细节（A、D）
- **承诺词库（收尾）**：颠覆你[的三观]／人性最[黑暗]／原著被删[减的真相]／隐藏细节／[战争美学]有多[强]
- **书名号规则**：影片知名度高时写进书名号（《红海行动》《沉默的羔羊》《禁闭岛》）；
  影片冷门或想用"剧情奇观"当卖点时**隐去片名**，改用剧情碎片当标题（A、C、D）。

### 7.3 可套用标题模板（四式）

## 8. 生成时的可执行清单（Checklist）

**开场（30–60 秒，10–30 行口播）**
- [ ] 第 1 句必须是钩子，**不许报名字**。从六式里选 1 式（争议片→三式，长稿→五式，苦难片→一式，主旋律/动作→二式，改编片→四式，重发/里程碑→六式）。
- [ ] 钩子里必须有**一个可核查的外部事实**（数字/评分/悬赏/原著/粉丝数）。
- [ ] 钩子里必须有**一句知情落差**（"只有我知道" / "很多观众不知道" / "事实真是这样吗" / "我们从未真正理解"）。
- [ ] 报名前或报名后插"本期承诺"（隐藏细节 / 全新解读 / 解密游戏 / 爆肝工作量），争议片承诺后补免责声明。
