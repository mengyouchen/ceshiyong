## 3. 【关键问题】复述与解读怎么交织

### 结论：**边讲边插，绝不"先复述完再统一解读"。** 6/6 篇成立。

**五条可操作规律：**

1. **英文 = 原片原声被 ASR 识别出来的痕迹，不是图图的口播。** 铁证：D《刺杀小说家》是国产片，**英文行数为 0**；A《红海行动》也是国产片，只有 2 簇（532–543 反派用英语审问夏楠、754–755 中国海军英语喊话），全都是原片里真的说英语的那两场。片子说什么语言，稿子里就有什么。

2. **原声是"净区豁免"的：自报家门、恰饭、署名套语里 100% 没有英文（6 篇 0 例外）。** 这几段是图图纯口播，原片声轨被完全压掉。

3. **开场存在"原声静默区"。** B 全片前 243 行（11%）零英文——即冷开场 + 自报家门 + 恰饭 + 背景铺垫 + 开场蒙太奇复述 + 解读① 全程由图图一个人说完。C 前 138 行（7.5%）同理。**结论：开场至少前 8–11% 不放原声，先把观众交给"图图这个人"。**
   例外：F 在第 9–11 行（冷开场内）就放了原声——因为它的钩子模板是"我要剪这部电影给你听"（F 13），情绪先于讲述。

4. **三个高频落点**：(a) 角色第一次正式对话/自我介绍（C 139–154 克劳福德布置任务、C 337–369 汉尼拔初见）；(b) 剧情揭底的关键台词（B 1734–1774 anagram 揭穿、B 357–358 密码英文原文、B 1996–2009 `To live as a monster or to die as a good man`）；(c) 情绪爆发（哭喊/审讯/威胁：B 663–675 妻子化灰、B 1629–1644 典狱长暴力宣言、A 532–543）。

5. **原声也可以出现在解读段内部——此时它是"被分析的样本"。**
   B 1271–1343 是一整段梦境逐帧拆解，英文 1273–1274、1288–1289、1316–1323 嵌在其中，每段原声后紧跟一句解读：
   > 1271 `而接下来我们又会看到一大段破碎和混乱的蒙太奇` / 1272 `咱们一点点来分析` / 1273–1274 [原声] / 1275 `这时候，酒壶的反光映照在泰迪脸上` / 1276 `这形成了一种针对泰迪的拷问`

6. **两篇把全片最后一行留给原片台词**（A 755 `please turn around immediately`；C 1844 `but i'm having an old friend for d`）——都是没有署名套语的那两篇。**有署名套语的篇目，最后一行一定是图图自己的声音。**

7. **图图从不逐句翻译原声。** 原声前一句中文交代情境，原声后一句中文直接接着讲下去。原声承担的是"情绪/氛围填充"和"证据出示"，不是"信息传递"。

## 5. 可操作结论：怎么排一篇"图图式解说稿"

**以 80 分钟旗舰长片（约 2000 行 / 3 万字）为基准，按比例缩放。**

```
① 冷开场钩子              1%–2%（20–40 行）   ← 必须。四选一：倒计时 / 悬案清单 / 翻案宣言 / 数据+情感契约
                                                铁律：绝不从影片开头讲起，并明说"今天不想从影片的开始切入"
② 自报家门 + 先赞后看      0.5%（10–14 行）    ← 放在钩子之后，绝不第一句。可与片头恰饭合并
③ 背景铺垫                0%–1.5%（0–32 行）  ← 只在"不补课看不懂"时才写，且最后一句必须落回影片本身
④ 主体（复述 × 解读交织）  85%–90%
     · 解读占主体的 20%–31%，单段 29–42 行（75–105 秒）
     · 每 60–180 行剧情挂一段解读（密度上限见 B：每 97 行一次）
     · 第一个解读插入点必须落在全片前 8% 以内
     · 中插恰饭 1 条，位置 ≈23%，长 13–63 行，必须从剧情物件借力换挡，结束后一句直接回剧情
⑤ 收束                    1%–5%（20–115 行）  ← 四选一：升华点题 / 悬念清单+下期预告 / 写稿自白 / 公益呼吁
⑥ 署名套语                0.2%（5 行）        ← "土[图]味电影解读 / 不善言辞但能说会道 / 拒绝影视解说快餐话 / 下期与你不见不散"
⑦ 片尾恰饭（可选）         0.4%（9 行）
```

**十条硬规则（每条都有上面的行号做背书）：**

1. **不许先复述完再解读。** 6/6 篇都是边讲边插，第一个插入点在 2%–7.7% 之间。
2. **解读段不要超过 100 行。** 全语料最长 97 行（E 399–495），第二长 84 行（D 986–1069）；超过这个长度观众会掉。
3. **进解读必须有明确的"进场句"**，三选一：`我一个＜荒诞身份＞的朋友告诉我` / `注意看…` / `你会发现…`。变装梗每篇用 1–7 次，是最强的个人标记。
4. **回剧情必须有短返场句**，5 个字以内最好：`继续说故事` / `咱们继续来说故事` / `继续看XXX的调查`。不要解释"刚才说完了"。
5. **触发解读只用这 7 类事由**：非常规镜头语言 / 伏笔埋与收 / 原著差异 / 需要外部知识 / 角色第一次出场 / 观众公认看不懂处 / 演员微动作。**不要为了解读而解读**——图图每一次插入都是对着屏幕上正在发生的一个具体现象。
6. **原著差异要给硬数字。** B 479–485 给词频（暴风雨 30+ 次、暴力 20+ 次），比"原著更压抑"有说服力十倍。
7. **埋"二级钩子"并在后面兑现。** `这里咱们先留一个钩子/后面还会再聊`（B 251）→ B 1609 兑现。一篇长稿至少埋 3–5 个（B 埋了 251/491/977/1240/1307 五处）。
8. **给观众一个可以动手的任务。** `你可以暂停视频/找张纸把密码给抄下来`（B 345–347）、`感兴趣的朋友可以暂停观看`（E 317）。这是把 90 分钟撑住的关键。
9. **恰饭不要硬切。** 从当前画面里正在出现的物件/状态借一句话换挡（汉尼拔的美食→电动牙刷，配角秃头→防脱洗发水，原著几十万字→AI 笔记本），结束后下一句直接是剧情，一个字都不多说。
10. **原片原声保留、不翻译、不侵入个人段落。** 原声只放在剧情复述和解读取证处；自报家门、恰饭、署名段绝对纯口播。如果不写署名套语，就把最后一句留给原片台词（A/C）。

**三个变体触发条件（什么时候可以破格）：**
- **主题分析向**（A）：标题承诺的是某个专题（"战争美学"）而非全片解读 → 可砍掉自报家门、恰饭、收束、署名，只留"钩子 + 交织主体 + 原声收尾"。
- **重制版**（C）：老片重发 → 用"履历叙事"（我以前做过/没火/我涨粉了/我回来重做）替代钩子；解读从块状插入改成逐句带读；可不写收束和署名。
- **公益向**（F）：把恰饭挪到 85%+ 且换成公益项目；收束不谈电影艺术，谈现实诉求。
- **国产片**（A/D）：稿子里不会有英文原声行，中文原声直接混进复述，可以把原声金句回扣到冷开场（D 第 1 行 `冒蓝火的加特林你见过吗` → D 1943 原声复现）。
