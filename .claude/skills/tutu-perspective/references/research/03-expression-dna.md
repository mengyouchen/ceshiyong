**难道 只有 3 次 —— 图图基本不用"难道"这种带压迫感的反问。**

设问的位置分布（按行号 % 定位，`grep -n` + awk）：设问句呈**两端重、中间是章节铰链**的分布。

**三种且仅有三种使用场合：**

**① 开场 0-5%：抛悬念钩子（每篇 1-3 个，连发）**
```

F3:53  马哈拉贾为什么会特地请假陪孩子购物
```
**② 中段章节交界：换段落的"下一个问题是"（不是制造悬念，是列议程）**
```
F6:490   为什么一定要强调暴力和暴风雨
F6:646   日条四的法则到底怎样破解四的法则

F3:1189  麻辣甲为什么会对伤害自己的人如此友善
```
**③ 结尾 93-100%：留问题给评论区（每篇密集爆发 3-8 个）**
```
F4:2004-2013  例如黑甲的来历究竟是什么 / 以及骗我为何神似黑甲的独眼 /
              事发身后的男子是九天吗 / 为什么依旧执念成生

              他与泰迪之间的婚姻关系到底在隐喻着什么
F4:2019       有没有些许不一样的看法呢
```

**反向铺垫式：`这也是为什么X`（16 次，行首 15 次）** —— 先给答案、再补原因，是图图把设问**倒过来用**的高频变体：

### 2.2 签名句式：`不是 X / 而是 Y`（跨两行的否定-修正）

命令依据：`grep -c '^而是'` = **50 次**（`而是` 总计 54 次，即 93% 出现在行首）

这是全语料**出现频次最高的有辨识度句式**，平均每篇 8.3 次、每 190 行一次。
前行均长 12.1 字，`而是`行均长 11.4 字 —— 两行几乎等长，形成"打拍子"的对称。

## 11. 单期骨架模板（由上述规则拼合）

```
【开场钩子 1-10 行】
  数字/反差事实 2-4 行（84万粉丝 / 全球1.2亿孩子 / 豆瓣68万人评6.5分 / 70万悬赏一个垃圾桶）
  设问 1-3 句连发（…吗 / 为什么…）
  ≤8 字的短句落锤 1 行

【自我介绍 11-16 行】
  你好，我是不善言辞的图图
  （本期缘由一句：收到儿童公益组织邀请 / 三刷并读完原著 / 爆肝一个月）
  先赞后看 / 腰缠万贯 / 爱你啾咪

【第一段原声 5-6% 处】5-11 行原片，前垫一句、后接一句 ≤10 字短句

【主体：N 个"看-解-锤"循环】每循环 20-40 行
  时间/地点前置独立行（夜幕降临 / 与此同时）
  3-5 行客观画面描述（镜头拟人化，位置即权力）
  1-2 行判断落锤（暗示了 / 象征着 / 也就意味着）
  每 2-3 个循环插入一次：
    · 我一个 XX 的朋友告诉我 + 4-8 行知识科普（长句可连跑）
    · 一组"不是X / 而是Y"重锤
    · 一次原声留存（5-10 行）
    · 章节交界设问一句
  情绪段连续 ≤8 行，第 9 行必须切回术语/判断

【揭底 80%-93%】
  最长的一块原声（可 26-41 行）
  接回："到这里为止" → 结论 3-5 行
  "这是我认为的 XX 里面最精髓的一部分"（全篇唯一一次的价值排序）

【结局段 93%-98%】
  只写事实（判决 / 下落 / 遗体 / 护照），不写形容词
  一句 ≤5 字设问留白（"阿里德呢"）
  最后一句话交给原片原声

【收尾 最后 8-12 行】
  3-8 句设问连发（留给评论区的问题）
  互动承诺（欢迎评论区留言 / 我看到了会在摸鱼时回复啊 / 如果没有回复就说明孩子忙到没有时间摸鱼啦）
  希望大家能喜欢这次的过度解读
  不善言辞但能说会道
  拒绝影视解说快餐话
  下期与你不见不散
```
