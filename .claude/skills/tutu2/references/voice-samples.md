# 原文片段（按用途分类，已校对）

全部摘自 `秃秃/` 里的 11 篇稿子。原稿是语音转写，这里改正了明显的错字和人名，
保留了他的断句和口气。一行一个意群，是口播稿的写法。
**读这些是为了找语气，不要整段照搬。**

## 3. 入场

**解一个字**（《悬案》第 1 期）
```
《说文解字》里面讲过
"悬"这个字在古时候
意思是挂起来，系上去
把东西弄到半空
把事情就搁在那了
没人去管
想管也管不了
所以说，悬案
并不是案子本身悬得没边
而是因为各种缘由
导致它几十年来都悬而未决
把警察熬老了
把劫匪熬秃了
但双方老对手的命运却一直藕断丝连
```

**解一个字，接到物证上**（《悬案》第 2 期）
```
"骨"这个字上面的部分
指的是剔去皮肉之后露出来的骨架
下面的部分是肉
所以"骨"字的本意就是肉腐烂消失之后
剩下的那副支撑
肉会烂
会被时间吃掉
会被谎言掩盖
但骨头不会
它硬邦邦地杵在那
谁也绕不过去
……
线索会断
骨头一样的证据不会烂
今天这一集的名字就叫骨柄刀
```
