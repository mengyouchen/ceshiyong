# 03 · 叙事结构（基于 20 篇语料）

## 三种叙事模式（按题材切换）

### A. 标准剧情解说（主力，≈15/20）
线性复述剧情 + 关键节点插入"创作者议论金句"。结构骨架：

```
【钩子】极端结果/反差前置 + 追问 + 片名信息背书（前 8-20 句）
【立人物+困境】交代主角身份与他被困住的处境
【推进·三跌】事件层层加码，主角不断被生活/体制/家庭击打
   每一跌后常插一句社会学/心理学议论拔高（"这恰恰是现代社会的困境…"）
【谷底/真相揭露】最沉重的一幕：秘密被揭开 / 主角崩溃 / 悲剧发生
【转折或沉底】或迎来和解微光，或彻底走向毁灭（心影不强求圆满）
【升华结尾】从具体故事抽象到普世经验 + "愿…"式祝福/追问（见 05）
```

### B. 拉片/影评式（Funny Games、酒精计划部分）
不复述剧情，而是**逐场拆解导演手法与主题**。第一人称"我"主导。
- "导演哈内克这么做有两个目的…"
- "所谓的契诃夫之枪，是编剧界的一条黄金法则…"
- 大量分析镜头语言、叙事陷阱、第四面墙、导演意图

### C. 第二人称沉浸式（Two Distant Strangers）
全程"你"，让观众亲历主角的每一次死亡循环，结尾切回现实做议论（真实死者名单）。

## 节奏与位置规律

- **议论穿插密度高**：平均每 3-5 个剧情段就插一句"创作者评论/社会学解读"。这是心影区别于纯复述号的核心——他**边讲边评**。
- **真相/反转留在 70-90% 处**：好孩子（哥哥才是偷钱者+领养真相）、深度安静（父亲性侵真相）、失明（母子爱上同一人被揭穿）、柔似蜜（母亲患癌决定杀子）——最大秘密都压到后段引爆。
- **悲剧不回避**：虎毒不食子（母子双亡）、深度安静（一尸两命）、柔似蜜（杀子+狱中病逝）、骑手（骑手脑死亡拔管）——允许彻底的黑暗结局，不强行 happy ending。
- **复合情绪**：即便走向毁灭也会在结尾给一束"理解的微光/普世的温柔"。

## 关键议论句式（穿插用）

- "在这个家里，X 是…，Y 是…，只有 Z 是那个永远在…的人"（三元对照定性，虎毒不食子）
- "这恰恰是现代社会的一个困境 / 我们习惯了用流程和规则来指导行为…"（骑手）
- "我们很多人都有类似的经历 / 父母的爱很重 / 重到让我们喘不过气"（千年敬祈）
- "你会发现子女身上所有别扭和拧巴的地方 / 根源往往都能在父母身上找到"（千年敬祈）
- "原来最绝望的不是死 / 而是满怀期待的生"（虎毒不食子）
