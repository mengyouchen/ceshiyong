# 02 · 开头钩子模式（基于 20 篇语料）

心影之剪的钩子核心 = **把全片最惊悚 / 最反差 / 最不可思议的"结局或核心冲突"直接抛在第一句**，制造"她到底经历了什么"的强烈追问，然后才慢慢倒回去讲。

## 5 大开头模板

### 模板 1：「极端结局前置 + 追问"究竟"」（最高频，强情绪型）
先抛一个骇人听闻的结果，再用"究竟要…才会…"逼出追问。
- "一个刚生完孩子的母亲 / 究竟要经历怎样的绝望 / 才会抱着自己半岁的孩子去自杀"（虎毒不食子）
- "她怀孕整整六个月 / 最终却落了个一尸两命的结局 / 只因腹中怀的是个女孩"（深度安静）
- "他买下一把手枪…最后举枪瞄准了熟睡的儿子…这是一个华裔母亲为她刚满18岁的儿子精心筹划的生日礼物"（柔似蜜）

### 模板 2：「直接提问/假设，把观众拉进道德困境」（代入型）
用"你会怎么选 / 当你…"把观众放在主角位置。
- "当你突然发现孩子的性取向有问题 / 你会选择去包容理解他 / 还是强行让他回归正常"（泡菜）
- "问你一个问题 / 一个刚生完孩子的母亲…"（虎毒不食子变体）
- "外卖员的配送时间能不能再压缩一下 / 他刚下令压缩了配送时间 / 结果下班后就开车把自家外卖小哥撞飞"（骑手·荒诞反差型）

### 模板 3：「禁忌关系/惊人反差一句话立钩」（八卦悬念型）
- "他从未想过自己会爱上妈妈的女朋友 / 更没料到这个秘密会被母亲揭穿 / 母子二人竟然爱上同一个女人"（失明）
- "一个'生不了孩子'的女人和她的学生 / 婚姻到底困住了谁"（不孕华文老师）

### 模板 4：「沉浸式'你'+ 类型反转」（第二人称代入，反类型题材专用）
全程第二人称"你"，让观众亲历，常用于反种族/反暴力题材。
- "作为一个身体素质拉满的黑人小伙 / 你对自己昨晚的表现非常满意…你就这样在众目睽睽之下被活活勒死在女友公寓门口 / 你临死前的最后一个念头是 / 你只不过是想回家喂狗而已"（Two Distant Strangers）

### 模板 5：「冷开场动作/反常细节 + 揭晓身份」（拉片/传奇人物型）
直接切入一个反常动作或场景，制造"这是什么人/什么片"的疑问。
- "他随身携带酒精测试仪 / 把自己锁在学校厕所里 / 仰头喝下一大口伏特加…确认数值精准达到0.05%"（酒精计划）
- "老人充满好奇的打开后备箱…没想到里面竟藏着200kg毒品"（骡子）
- "就因为儿子开了一辆日本车 / 老爷子便在背后刻薄地骂道"（老爷车）
- "说实话，这可能是我看过最具挑战性的电影之一"（Funny Games 拉片·第一人称影评开场）

## 钩子规律

1. **第一句必须是"反常事实/极端结果/惊人反差"**，绝不用"今天给大家讲个电影"
2. **影片信息（片名、主演、奖项、豆瓣分）通常延迟到钩子之后**才补：
   - "这部新加坡年度催泪神作《好孩子》将带我们见证…"
   - "这部由刘玉玲主演的电影《柔似蜜》将撕开…"
   - "这部2021年获得奥斯卡的丹麦电影《酒精计划》…"
   - "金马奖7项提名"、"豆瓣8.6高分"作为标题/钩子的信任背书
3. **钩子里常嵌一句"创作者评论"定调主题**："而留白往往意味着最大的恐惧"、"当一个父亲对女儿的爱只能通过在心里默默祈祷来表达时，这份爱就已经变质了"
4. **善用悬念词**：竟然 / 却 / 没想到 / 直到 / 只因 / 究竟
