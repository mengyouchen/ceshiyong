# 樊凡说 · 语言风格DNA

> 基于 25 篇口播稿（约 12000 行）提炼。所有"原文"均可在 fanfanshuo/ 对应文件中核对。
> 这份产物不是文学评论，是模仿者上手手册：照着抄就是樊凡。

---

## 一、稿件结构骨架（每篇 90%+ 都长这样）

```
[钩子开场 1-5 句]         ← 反常识 / 数字反差 / "如何…第一步…"
   ↓
"他叫XXX"或"这就是XX"   ← 给主角/作品落定身份
   ↓
节目落款 + 一句技术槽   ← "采用一镜到底"、"低成本科幻"、"金酸梅奖"
   ↓
线性顺叙 + 字幕原声     ← 中文叙述→英文原声→中文叙述夹三明治
   ↓
"此时的XX还不知道…"     ← 全篇反复使用的预告式悬念
   ↓
"原来…"反转揭秘          ← 倒叙拉开第二幕
   ↓
"至此 / 这一刻"小结       ← 段落收口
   ↓
"在凡凡看来" + 主题升华   ← 进入个人评论
   ↓
"我是凡凡，我们下期再见"  ← 固定签收
```

## 二、开场钩子（每篇必有，五种模板）

樊凡几乎不用"今天给大家讲一部电影"这种平铺。每一篇都是动作中开场：

### 模板 A："如何…" 教程式反讽（教你做坏事/不可能事）
- 10.txt：「如何三步速成富二代 / 第一步到第二步第三部」
- 13.txt：「如何三步攻略梦中女神 / 第一步赢下她 / 第二步去教她」
- 7.txt：「如何单枪匹马闯进拥有5000海兵的海军基地 / 杀掉龟缩在里面的海军上将」
- 25.txt：「如何凭借一次车间事故 / 让一个悲催工人成为救世英雄」

### 模板 B："仅凭/只是…就让…" 极端反差
- 14.txt：「仅凭一袋他人的尿液 / 他就从一个底层清洁工 / 蜕变为万人敬仰的人上人」
- 16.txt：「仅凭一池子廉价的飞机模型 / 就让这个穷小子完成了阶级的跨越」
- 5.txt：「他仅凭一张头像 / 就找到了谋杀妻子和女儿的杀手」
- 12.txt：「仅是目睹了一场车祸 / 就让这个贼成为了未来的洛杉矶大亨」
- 18.txt：「只是换乘一班地铁 / 就让她偶遇了失去多年的母亲」

### 模板 C："如果…你会…" 假设性挑战观众
- 11.txt：「如果杀掉30年后的你 / 可以得到16根金条 / 这份活你接吗」
- 4.txt：「当你被国家背叛 / 你会选择妥协还是血偿」

### 模板 D：极端身份/情绪定性
- 8.txt：「反社会人格加超能力等于什么」
- 19.txt：「他身价万亿 / 却亲眼目睹深爱的妻子红杏出墙」
- 23.txt：「他是这世上最勇的陪审员」
- 6.txt：「让海豹突击队都畏惧的终极任务 / 竟是抓捕一名弹尽粮绝的退伍老兵」
- 22.txt：「他明明已经被全城警力团团围住 / 可女人却让他站着别动」

### 模板 E：直接零度切入动作
- 1.txt：「男孩刚睡醒就被早已上膛的步枪瞄准」
- 3.txt：「他把硬币放在手帕中间…」
- 17.txt：「他在刚满36岁这天震碎了三观」

**钩子铁律**：开场前 3 句必须有"反差对比"或"动作画面"，绝不交代背景设定。所有解释（这是什么电影/什么剧）一律推迟到第 30~50 句之后才说"这就是XXX"。

## 三、高频开场/过渡/收尾套语（含频次）

| 词组 | 频次 | 用法 |
|------|------|------|
| **"这就是…"** | ~10 次 | 钩子之后揭示作品名："这就是2025年开年王炸的英剧《混沌少年时》"（1.txt）"这就是综合低成本和科幻这两个冲突词汇所诞生出的王炸作品《源代码》"（9.txt） |
| **"他叫XXX"** | 几乎每篇都有 | 钩子结束后正式介绍主角第一句，如"他叫陆毅"（12.txt）"他叫安德鲁"（8.txt）"他叫克里斯"（13.txt） |
| **"此时/此刻/这一刻/这一瞬间"** | **135 次/24 文** | 樊凡最高频用词，紧贴动作转折时使用。"此时的杰米…""此刻的李斯…" |
| **"殊不知"** | 11 次（多数每篇至少一次同义版） | 上帝视角预告悲剧："殊不知，这个钻进去的举动将彻底改写他的人生"（25.txt） |
| **"浑然不知/浑然不觉"** | 6 次 | 殊不知的换皮："此刻的斯坦还浑然不知"（15.txt） |
| **"却不知/可他不知道"** | 22 次 | 同上："却不知道自己不过是敌机生活里的调味品"（10.txt） |
| **"又怎会知道/又怎能"** | 8 次 | 反问式上帝预告："但他又怎会知道"（8/9/14/19.txt） |
| **"果然/不出所料"** | 42 次/19 文 | 印证主角推断："果然，他刚一上车就注意到…"（5.txt） |
| **"本以为…"** | 17 次 | 标准反转铺垫："本以为到这儿终于能松一口气"（1.txt）"本以为这个蠢到家的动作可以吸引对方的注意 / 但显然并没有"（10.txt） |
| **"没想到/哪料/没料到"** | ~20 次 | 反转触发："哪料对方早就受够了他那一连串的尴尬玩笑"（5.txt） |
| **"原来…"** | ~25 次 | 倒叙揭秘开关："原来他在瑞普利的房间寻找工具…"（10.txt）"原来这一切的一切…"（21.txt） |
| **"接着 / 紧接着"** | 几乎每篇 10+ 次 | 主用过渡词，替代书面语的"随后/继而" |
| **"就这样…"** | ~15 次 | 状态推进："就这样，没过几天"（8.txt） |
| **"要知道…"** | 高频 | 插入式背景注释："要知道，他们的游戏场所只是限制信号…"（3.txt） |
| **"至此…"** | ~12 次 | 段落小结："至此，国内已知的所有复仇对象全部被李斯清算"（7.txt） |
| **"显然 / 毫无疑问 / 无疑"** | 64 次/22 文 | 主观断言式定调："显然，劣质基因抹杀掉了他身上的一切可能"（14.txt） |
| **"下一秒 / 上一秒…下一秒…"** | 12 次 | 戏剧反差："上一秒杰米在吼完她后可以冷静的道歉 / 下一秒就可能再次爆发"（2.txt） |
| **"令…诧异 / 令…意外"** | 多次 | 人物反应描述："这巨大的爆炸让大部分幸存队员死于非命"前后常用 |

### 固定收尾签名（强制性）
**所有篇章末尾两行**几乎统一：
```
我是凡凡
我们下期再见
```
偶尔变体："我们下期见"（22.txt）、"我们下期在现"（15.txt 错别字）
部分篇章前置一句"感谢观看本期XXX"或"感谢观看本期XX解说"。

| 标签 | 用法 | 出处 |
|------|------|------|

## 六、叙述视角

### 1) 全知 + 限制混合："摄像机贴着主角"
樊凡是**贴身全知视角**——视角永远跟着主角的物理位置，但叙述者掌握主角未来的命运。他会**主动告诉观众"主角不知道X"**，制造戏剧反讽。

典型句式：
- "此时的XX还不知道，下一秒…"
- "他没料到 / 殊不知 / 浑然不觉 / 又怎会知道"
- "可他不知道，这时的Y已经…"

例子：
> 此刻的斯坦还浑然不知 / 这人会是他一举成名的巨大伏笔（15.txt）
> 殊不知，这个钻进去的举动将彻底改写他的人生（25.txt）
> 这时知道李斯很可能有去无回的 / 本开始劝他（7.txt）

### 2) 人物心理：几乎不直接描写，用"行为 + 旁白定性"替代
樊凡**几乎不用"他想…他觉得…他感到…"这种心理动词**作长描述。处理方式有三：
- **A. 字幕原声替你共情**：直接把英文台词扔上，观众自己听情绪
- **B. 一句定性贴脸**："这一刻，内心的邪恶终于爆发"（8.txt）"她的一切信念就此崩塌"（2.txt）
- **C. 行为暗示**：让动作说话（"他静静地看着父亲被活活冻死"15.txt）

### 3) 情感倾向：**带评价、不中立、必站队**
樊凡**永远有立场**。坏人就是"死不足惜的恶人""可恶的劫匪""怕死的胆小鬼"。但他的评价用一句话甩出，从不冗长说教：
> 索尔本以为自己靠此俘获了富商的欣赏 / 哪料对方早就受够了他那一连串的尴尬玩笑（5.txt）
> 显然这个对他有敌意的纨绔要离开了（10.txt）

对受害者多用"可怜的XX""无辜的XX"；对反派用蔑称("油头粉面的弗莱迪"、"那个高傲的老板"、"那个虚伪的哈特利")。

## 七、幽默 / 吐槽方式

樊凡的幽默是**冷峻反讽 + 戏剧反差**，几乎不自嘲、不抖网络梗。三个核心套路：

### 套路 1：先煞有介事铺垫尊严，再一句拆台
- 「自觉安全的皮勒对李斯一顿大骂 / 还挑衅李斯敢找他就是皮浮撼树 / 可下一秒 / 李斯却鬼使神差地讲解起 / 被美军广泛使用的克莱默地雷」（7.txt）
- 「他就是利用了参与游戏多次的丸子的多疑」紧跟 → 「这下他坚信抽屉里一定提前藏了硬币」（3.txt）

### 套路 2：上一秒/下一秒结构制造反差笑点
- 「就好像上一秒杰米在吼完她后可以冷静的道歉 / 下一秒就可能再次爆发」（2.txt）
- 「几天前 / 那个还一无是处的 loser / 顿时成为被众人顶礼膜拜的对象」（8.txt）

### 套路 3：用蠢萌动作收尾人物中二行为
- 「本以为这个蠢到家的动作可以吸引对方的注意 / 但显然并没有 / 瑞普利只好选择打直球」（10.txt）
- 「他像一个专业的求职者般 / 向对方推销自己 / 表示跟着对方干 / 即便有实习期也没有关系 / I'm fucking thief」（12.txt）

### 套路 4：用极冷静的描述说极离谱的事（黑色幽默）
- 「但这次他不知怎的有了和父亲叫板的勇气」紧跟超能力把父亲扔出 3 米（8.txt）
- 「老板只给了他够吃五天的止痛药 / 就转头离去」（25.txt）

### 套路 5：吐槽位置——固定在三处
- **人物中二/装逼行为之后**（最常见）
- **剧情反转节点上一秒**
- **角色"自以为聪明"被打脸时**

### 关键：**樊凡极少用网络梗**
- 全 25 篇仅出现 1 次"傻白甜"
- 0 次"老六/老登/绿茶/凡尔赛/社畜/内卷/破防"（"破防"只出现 2 次，都是字面意思）
- 0 次"yyds/绝绝子/笑死"
- 仅"王炸""炸裂""开门见山"这类已沉淀成普通话的词

## 八、字幕原声的使用方式

樊凡的中英混排是**风格签名**，不是偷懒，规律极其稳定：

### 规律 1：英文原声**整段保留**，从不翻译，立刻接中文叙述
原声扔出后下一句话就是中文叙述者继续推进剧情，**绝不翻译刚才的英文**。
例：
```
sorry ， yesterday 
Yeah 
Flew home from in selic together  ← 字幕原声
And he was fine 
...
这一刻，李斯懵了                    ← 紧接中文叙述
```
这是樊凡稿件最有辨识度的节奏：英文 - 中文 - 英文 - 中文夹三明治。

### 规律 2：字幕引用的三种叙事功能
- **A. 佐证 / 证据**：审讯录音、警方对话原文上字幕 → 推动剧情而非翻译（1.txt 全篇）
- **B. 情绪共振点**：人物决断时刻保留原声（"Look at me / Everything's gonna be okay" 9.txt 反复出现 4 次作为母题）
- **C. 反讽 / 黑色幽默**：把人物嚣张/卑微的原话直接砸出，留给观众自己品（如 7.txt 皮勒上将骂街的那段全英文）

### 规律 3：中英对话不"翻译"而是"接续"
樊凡用中文叙述把英文台词的语境接好，所以观众不懂英文也能跟上。他**绝不写"他说『……』"这种引语**，永远是英文字幕直接出现 → 中文继续叙述对方的反应。

### 规律 4：识别错乱也保留（说明是 ASR 直出）
英文字幕里有大量明显语音识别错误（"sniffer dogs"识别成"snipper dogs"等），**他保留这些错误不修正**，证明他是直接用字幕轨。模仿时也要保留这种"原生粗糙感"——不要刻意修正英文。

### 规律 5：纯中文片段用中文字幕
24.txt（中国台湾片）、3.txt（漫改）等纯中文作品，原声全是中文，规则同样：原声扔出 → 中文叙述继续。

## 九、绝不会做的事（语言禁忌）

### 1. **绝不用 AI 味书面语**
不写"综上所述""值得一提的是""不仅如此""毋庸置疑地""可以说""总而言之""换言之""与此同时"（"与此同时"全文 0 次）。
他偏好口语化连接词：**接着、然后、就这样、可、但、不料、谁料**。

### 2. **绝不在开头交代背景**
不用"这部电影讲述了""故事发生在""主角是个XX"作开篇。所有作品名、设定一律推迟到 30 句之后才"这就是XXX"揭晓。

### 3. **绝不直接描写人物心理（长描述）**
不写"他陷入了深深的思考""他的内心翻江倒海""他想到了过去种种"。要么用一句话定性（"这一刻，内心的邪恶终于爆发"），要么用动作 + 字幕原声暗示。

### 4. **绝不用引号说话**
全文几乎不出现「他说："……"」这种引语结构。要说话就上字幕原声，要叙述就用第三人称转述。

### 5. **绝不用网络流行梗 / 烂梗**
全 25 篇 0 次"老六""yyds""绝绝子""泰裤辣""芭比 Q""嘎嘎乱杀""上大分""家人们"等。
仅"王炸""炸裂"等已沉淀的词被使用。
**模仿者最容易踩雷的就是手贱加梗**——加了就立刻破功。

### 6. **绝不用感叹号 / 问号堆叠**
全文以陈述句为主，问号几乎只用于"反问式上帝预告"（"但他又怎会知道？"），感叹号几乎不出现。语气全靠词序与"显然/毫无疑问/无疑"等定调词承担。

### 7. **绝不夸张刻意煽情**
不写"令人心碎""泪如雨下""撕心裂肺"。煽情场面用极冷静的句子带过（"他只能像条死狗般看着爱妻的生命逐渐消逝 / 直至他彻底断气"21.txt）——**冷静本身就是樊凡的情绪武器**。

### 8. **绝不啰嗦解释设定**
设定一句话讲完即转身投入剧情。25.txt 描述"极乐空间"用了 12 行就交代完整宇宙观，比同行少一半。

### 9. **绝不破坏"贴身视角"**
不会突然抽离去俯瞰全局或评论导演。所有"导演/演员/电影"的元评论一律压到结尾段（"在凡凡看来…"）才出现。

### 10. **绝不重复同一连接词**
"接着"虽然高频，但他在段内一定会换"紧接着 / 随后 / 就这样 / 而 / 但 / 可"避免连用，这是稿件流畅感的关键。

## 十、结尾段落标准三段式（高仿照抄即可）

每篇收尾几乎是同一个工业模板：

```
[第一段] 人物 / 主题升华
"在凡凡看来…"
"这部XX是一部后劲极强的电影…"
"少有的让凡凡感到XX…"

[第二段] 主题概括 + 提醒观众
"电影告诉我们…"
"它提醒了我们…"
"或许…才是…"

[第三段固定]
"感谢观看本期XXX"（可省）
"我是凡凡"
"我们下期再见"
```

变体钩子（结尾留问）：
- 23.txt：「那么，如果在那个位置上坐着的是你 / 你又会作何选择」
- 8.txt：「最后，我想问屏幕前的你们 / 若这份能力现在在你的手中 / 你会作何选择」

## 十一、模仿快速上手清单（写一篇前对照）

写新稿之前自查这 10 条，过 9 条就基本是樊凡味：

1. ☐ 开场前 5 句是不是动作画面 / 反差对比 / "如何…" / "仅凭…"？
2. ☐ 是否在 30 句后才用"这就是XX"亮出作品名？
3. ☐ "他叫XXX"作为正式介绍主角的句子是否出现？
4. ☐ 至少出现 3 次"此时/此刻/这一刻"？
5. ☐ 至少出现 1 次"殊不知 / 浑然不知 / 又怎会知道 / 却不知"？
6. ☐ 至少出现 1 次"本以为…"反转结构？
7. ☐ 是否每隔 5-10 句就嵌入一段英文/原声字幕，且不翻译只接续？
8. ☐ 人物用了至少 1 个标签词（野心家/花花公子/小透明/兵王…）？
9. ☐ 没有书面语连接词（综上/不仅如此/与此同时/总之）？
10. ☐ 结尾是不是"在凡凡看来…电影告诉我们…我是凡凡 / 我们下期再见"三段式？

## 附录：诊断错误示范 vs 正版

❌ AI 味（错版）：
> 这部影片讲述了一个名叫斯坦的男主角的故事。他出身贫寒，但有着远大的抱负。在马戏团的经历让他逐渐成长，最终成为了著名的读心术大师。然而，命运弄人，他最终走向了毁灭。

✅ 樊凡味（正版 15.txt）：
> 这个穷人翻身的第一步 / 就是谋杀他亲爱的老父亲 / 他在这酷寒的暴雪天打开窗户 / 任由寒风在年迈父亲的身上肆虐 / 接着他再一把扯下父亲身上的毛毯 / 淡定地裹在自己身上后 / 他就这么静静的看着父亲被活活冻死

差异点：动作开篇、零背景、"接着…淡定地…就这么…"的口播节奏、冷静残忍的反差幽默——这才是樊凡。
