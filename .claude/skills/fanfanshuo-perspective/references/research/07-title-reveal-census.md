## 二、口碑翻案的位置铁律

「被低估/被骂/被名字耽误」这类翻案论证，原稿里**全部在结尾**，开头 0 次：

- 15.txt L566「这部被名字耽误的电影 / 少有的让凡凡感到后劲很大」
- 17.txt L579「有人觉得这部千禧年上映的黑洞频率 / 也有一些绕不开的时空悖论 / 但他远不止于…」
- 25.txt L385「这部漏洞颇多的极乐空间常受人诟病」
- 16.txt L767「这部电影也被很多人讲过 / 可凡凡发现 / 大多讲述的侧重点在…」

逻辑很朴素：**观众还没看过故事之前，翻案没有弹药；看完了，翻案才有说服力。**

## 三、对《遗落战境》产出的判罚

Skill 产出的那段：
「这就是 2013 年阿汤哥主演的科幻片《遗落战境》/
《创：战纪》导演科辛斯基的废土美学巅峰 /
一部当年被骂"缝合怪" 如今越看越冤的视觉神作」

三处违反语料：
1. **报了主演+导演**——非宣发稿的开头揭示从不报人名
2. **口碑翻案放开头**——语料里翻案全在结尾
3. **本不该开头揭示**——《遗落战境》没有须提前解释的形式亮点
   （废土美学不影响观看理解，不像伪纪录片抖动/一镜到底），
   按默认应片名后置，钩子直接滚进正片

病根：旧 SKILL.md 把「片名揭示段 13-30 行」写成了默认必选模块，
且《消失的爱人》范例（"2014年大卫·芬奇执导"）把报导演的习惯烙进了模板。

## 四、修订后的三档决策（已回写 SKILL.md）

```
片名揭示 = 三档决策 不是必选模块

第 1 档（默认 · 半数以上）：开头不报片名
  钩子砸完直接滚进正片
  片名压到结尾升华段起手：「这部 X 年上映的 X」
  或只在签收行带过：「感谢观看本期 X」

第 2 档（开头揭示 · 仅限三种触发）：
  a. 形式亮点需要提前功能性解释（一镜到底/伪纪录片会抖动）
  b. 片子标签自带反差卖点（「低成本+科幻」=源代码）
  c. 新片宣发稿（有档期任务）
  开头揭示时：不报导演/主演（宣发除外）
  年份可省 评价只用一个沉淀词（王炸/精彩绝伦）

第 3 档（全篇不报）：
  片名=主角名（瑞普利）或普通名词（夜行者）→ 正文自然消化
  剧集中间集 → 不重复报名

口碑翻案（被低估/被骂/被名字耽误）一律放结尾 开头 0 次
```
