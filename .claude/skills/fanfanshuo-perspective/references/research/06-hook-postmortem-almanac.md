## 二、Skill 产出的 8 个败因

| # | 败因 | Skill 产出 | 原稿做法 |
|---|------|-----------|---------|
| 1 | **情感伏笔漏牌** | 钩子全程没提父亲 | 第 2 行就埋「父亲留下的旧摄影机」，预告段直接开「见到已故的父亲」 |
| 2 | **反常缺对照系** | 直接砸"7岁录像里看到17岁的自己" | 先立正常（看到7岁的自己）再「但同时也」砸反常，力度翻倍 |
| 3 | **反应镜头偷懒** | 「所有人都说不出话了」一行糊过 | 「妹妹懵了/死党们也懵了」两行，节奏+人物介绍一石二鸟 |
| 4 | **缺观众代问** | 只给物证不给怀疑 | 「有可能是亲戚吗/不，衣服手表全都对上」——先替观众抵抗再击杀抵抗 |
| 5 | **收口抽象** | 「图纸掀开的第一页」文学悬念 | 三张具体支票递进（也将/甚至），中视频观众要承诺不要意境 |
| 6 | **原声占位过大** | 钩子期留 3-6 行大块占位 | 只微插 1 行「Let's check down here」动作递入 |
| 7 | **片名揭示信息密度错位** | 报年份+监制+口碑翻案三条影评信息 | 零背景资料；「喂，大家好」+「精彩绝伦」+功能性形式说明 |
| 8 | **结尾预判说教化** | 预设「科技反噬」告诫落点 | 明说拒绝「珍惜当下的空洞告诫」，改打因果闭环智性彩蛋 |

## 三、原稿结构上的两个反例（推翻旧规则）

1. **倒叙段不是必选项。** 26.txt 钩子取自影片开场戏本身，
   钩子砸完直接顺序推进，全篇无「几天前/原来」回拨；
   主角也没有「他叫大卫」式正式介绍，而是经由关系人带出
   （「大卫已故的父亲是赫赫有名的发明家」）。
   → 倒叙模块条件化：钩子取自中后段才启用。

2. **「大家好」不是禁词。** 旧调研写"区别于下沉博主（不用大家好）"，
   26.txt 第 19 行实证推翻。修正为：**「大家好」只许出现在
   钩子砸完之后的片名揭示位，绝不许出现在第 1 行。**
   启发式 4 的钩子重写线（钩子内出现「今天给大家」即重写）不变。

## 四、结尾段新发现：升华双开关

26.txt 结尾（449-482）完整走了一条旧 Skill 没覆盖的路径：

```
故事最后画面（大卫主动走向杰西 精准猜中她要说的话）
→ 收束段带 1 段关键原声当"彩蛋物证"
  （how did you know... / i think we're about to change the world）
→ 反问观众参与：「你们想到什么了吗」
→ 解读伏笔：「这个镜头和台词的真正意思是 /
   那个机器之所以会被造出来 / 恰恰是因为他回去了 /
   这是一个完美而有趣的因果闭环」
→ 明说拒绝空洞告诫：「凡凡不想在结尾给一个这么有趣的电影 /
   做一些珍惜当下和不要试图改变过去的空洞告诫」
→ 用"朴素事实"落地：「大卫用一整条被抹去的时间线 /
   换来了最后三秒钟的笃定 / 而我们不需要毁掉任何东西 /
   就能做到同样的事 / 这世上唯一真实的旅行 / 就是当下的每个瞬间」
→ 我是凡凡 / 我们下期再见
```

**规则修订**：
- 「升华段绝不插原声」保留，但收窄适用范围：**升华议论本体**不插原声；
  **画面收束段可以带 1 段关键原声作为被解读的物证**（彩蛋式回收）。
- 升华分双开关：黑暗/社会派片走 A（议题告诫）；
  有趣/高概念闭环片走 B（智性彩蛋：解读伏笔 → 拒绝说教声明 → 朴素事实）。
- B 开关的落点仍然是议题（自由意志/珍惜当下），但**包装是反说教的**——
  先骂一遍套路化告诫，再用具体物证式的一句话把同一个意思说出来。

## 五、其他语料增量（26.txt 顺手确认的既有规则）

- ASR 识别错误保留不改：「带带怎么巴适」「这轰你炮」「变命啊」「我是范范」✓
- 原声当纯情绪爆点：「what / holy shit」「no way / oh my god」一行惊叹词就是一拍 ✓
