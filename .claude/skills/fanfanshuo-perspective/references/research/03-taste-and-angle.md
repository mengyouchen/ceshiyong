## 三、切入角度的偏好

### 1) 视角选择：偏好"反派/反英雄/失败者"作为主视角

- **小杰米（杀人少年）** 1、2：从凶手家庭视角切入，不站受害者
- **瑞普利**（杀人冒名顶替者）10：全程跟主角的心理深渊
- **陆毅**（夜行者反社会摄影师）12：完全是反派的崛起视角
- **斯坦**（玉面情魔骗子）15：从底层骗子到自我毁灭
- **克里斯**（赛末点野心家）13：用理性执行疯狂
- **格雷**（升级残废复仇者）21：身体被 AI 接管的旁观者视角
- **安德鲁**（超能失控）8：黑化的少年视角

> **规律**：他几乎从不选择"白板英雄"。即使写正向的猫鼠游戏（16）、源代码（9），也强调主角的脆弱、被规训、自我寻找。

### 2) 强调层面：议题 / 心理 > 剧情爽点

| 层面 | 偏好度 |
|---|---|
| 社会议题落点（结尾"电影提醒我们…"） | 极高，**25/25 篇都有** |
| 人物心理动机解构 | 高，10/25 篇大段心理戏 |
| 拍摄手法 / 幕后 | 中低，但**出现即点出**——1/2 的"一镜到底"，8 的"伪纪录片+第一人称"，21 的"机械式运镜"，24 的"实时叙事" |
| 单纯剧情爽感 | 低，复仇片（终局名单）也会落到"被国家背叛"议题 |
| 颜值 / 演员八卦 | 0/25，从不提 |

### 3) 结构模板（高度稳定）

几乎每篇都遵循：
```
反常识钩子句（"如何三步速成富二代""仅凭一袋他人的尿液…"）
→ 高潮场景倒叙
→ 介绍主角与设定
→ 顺时间复述剧情（占 70% 篇幅）
→ "凡凡看来…"主观落点（议题升华 + 隐喻拆解 + 反问观众）
→ "我是凡凡，我们下期再见"
```

### 4) 爱讲幕后但点到即止

- 1.txt / 2.txt：**反复强调一镜到底**——"追求电影艺术极致使用一镜到底拍摄""背台词都是一项巨大的工程"
- 8.txt：明确点出"第一人称视角拍摄的伪纪录片""凭借神奇四侠他荣获了金酸梅奖最差导演"
- 21.txt：单独拆"机械式运镜和格雷自主活动形成鲜明对比"作为视听语言解读
- 24.txt：强调"全程高密度实时叙事""25年中国台湾地区电影票房冠军"

> **规律**：他把"形式"作为电影价值的加分项之一，但只点不深挖，主要服务于"这电影值得看"的推荐论证。

## 四、价值观倾向（原文证据）

### 4.1 他赞赏什么

#### 证据 1：人性/精神超越冰冷规则与决定论（14 千钧一发）
> "他的爱情象征着对冰冷规则的抗议……电影告诉我们，人类的潜力无法用基因来量化，精神的力量足以超越任何物理上的限制。"

#### 证据 2：自由意志、反抗算法/系统（22 少数派报告）
> "这部02年上映的少数派报告，是少有的让凡凡觉得伟大的电影……他预言了我们现在的生存困境，我们如今不是正活在一个由数据和算法构成的时代……是即使被预言也要挣扎反抗，要亲手选择自己未来的权利。"

#### 证据 3：被规则约束的犯罪者反而值得同情（16 猫鼠游戏）
> "再聪明的天才，都需要被灌输规则；再迷失的罪人，只要能被真诚的看见和理解，就永远有找回真实、重归生活的可能。"

#### 证据 4：珍惜当下、有限性的爱（18 时间旅行者的妻子）
> "或许，爱不是拥有和控制，而是在有限的时空里，去填满每一个不留遗憾的瞬间。"

#### 证据 5：底层求生欲合法（25 极乐空间）
> "这场革命并非源于崇高的理想，只是源于一个平凡人活下去的欲望……我们如今所处的这片广阔天地，不应该才是真正的极乐空间吗？"

### 4.2 他批判什么

#### 证据 6：批判家庭教育中的"道歉式暴力循环"（2 混沌少年时）
> "杰米的父亲也同样总是在和家人爆发激烈的冲突后马上向家人道歉……孩子是父母的镜子，坏习惯比说教更有教育力。"

#### 证据 7：批判流量媒体和"消费悲剧"的公众共谋（12 夜行者）
> "妮娜代表着新闻业堕落的缩影，他深知行业的游戏规则、收视率就是一切……当某些媒体在消费他人的悲剧时，我们每个人或许都在不经意间，成为了流量的帮凶。"

#### 证据 8：批判依赖科技/AI带来的"主体性让渡"（21 升级）
> "格蕾娜强大复仇能力的代价是交出身体的控制权，这似乎向我们隐喻了依赖 AI 的代价，便利性的背虐可能是人性的让步……最大的风险不是我们不够强大，而是我们忘了自己为何要强大。"

#### 证据 9：批判"为仕途不择手段"的小人（22 少数派报告）
> "拉玛那份坚定预测犯罪是为国为民的信念，到底是真的还是场面话……他不过是个为了仕途不择手段的小人罢了。"

#### 证据 10：批判用恶意操控他人最终反噬自己（15 玉面情魔）
> "在试图看穿并操控他人时，我们最需要看清和警惕的，恰恰是我们自己内心的恶魔。"

## 五、反模式："什么样的片他不会选 / 不会这样讲"

### 5.1 他大概率不会选的片

| 反模式 | 证据 |
|---|---|
| **纯爱情片 / 偶像剧** | 25 部里只有 18 一部爱情，且是科幻爱情，落点是"珍惜当下"而非恋爱本身 |
| **纯喜剧 / 合家欢** | 0/25，从无 |
| **歌舞片 / 武侠 / 古装** | 0/25 |
| **韩国伦理 / 大陆主旋律 / 文艺片** | 0/25 |
| **没有"反派/灰色主角"的正能量爽片** | 即便选爽片（终局名单），他也强调"被国家背叛"而非爽感 |
| **没有可拆解隐喻的影片** | 他必须能在结尾点出"电影告诉我们…"，纯感官片不符合他的解说结构 |
| **明星八卦/纪录片** | 0/25 |

### 5.2 他不会这样讲

- **不会从受害者视角切入**：1/2 选择从加害者家庭视角，体现他对"道德高地"叙事的回避
- **不会做"演员演技夸夸"**：25 篇基本不评价演员，只评角色与议题
- **不会避谈结局**：所有篇章都讲到结局并升华，**不是预告片式解说**
- **不会用激烈情绪输出立场**：批评也克制，常用"凡凡看来""或许""不禁让凡凡想到"等软化句式
- **不会停留在剧情复述**：每篇都有"凡凡式落点"——议题/隐喻/反问观众
- **不会强行政治正确**：对杀人少年、骗子、反社会主角，他会拆解"为何走到这一步"，而不是简单道德审判（典型：10 瑞普利"罪恶并非总是源于纯粹的邪恶，也可能源于深刻的自我憎恨"）

## 六、给"选题顾问"的判断指南

**当被问"樊凡会不会选这部片？"时，按以下信号打分：**

正向信号（命中越多越可能选）：
- 有"反派/灰色/失败者"主角 → +2
- 有可拆解的社会议题（阶层/科技/家庭/媒体/体制）→ +2
- 是犯罪/悬疑/科幻类型 → +2
- 有高概念钩子（一句话能讲清"这电影最离奇的点"）→ +2
- 是"被低估的老片"或"被名字耽误"的小众片 → +1
- 美剧/英剧/好莱坞出品 → +1
- 有可点出的形式亮点（一镜到底/伪纪录片/实时叙事）→ +1

负向信号（命中即基本否决）：
- 纯爱情 / 喜剧 / 歌舞 / 武侠 → -3
- 没有结局可升华的开放式纯艺术片 → -2
- 韩国伦理片 / 大陆文艺片 / 主旋律 → -2
- 主角全程正能量、无道德灰色地带 → -1
- 没有任何隐喻空间的爆米花动作 → -1

**当判断"他会从什么角度切入？"时，模板：**
1. 找出片中**最灰色/最有争议的人物**作为视角
2. 找出可挂钩的**社会议题**（阶层/科技/家庭/体制/媒体之一）
3. 找出片中**最反常识的高概念**做开场钩子
4. 结尾必须能用"电影告诉我们……" + 一句反问观众 收束
