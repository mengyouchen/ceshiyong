## 一、选题与角度分析（v1.3 重评）

**评分：9 / 10 —— 会做，做长片。落点：导演意图。**

| 项 | 判断 | 依据 |
|---|---|---|
| 门槛一·第二层 | ✅ | 镜头与选角层面的第二层：同一批演员在不同层的世界里各演一个人；"世界的边缘"出现两次；首尾两个画面（笛卡尔题词 / 屏幕缩成一道光熄灭） |
| 门槛二·镜头密度 | ✅ | 1937 与 1999 两层世界的影像处理不同（导演一度想把 1937 拍成黑白，被摄影师劝下——单一低权威来源，正片里需 hedge） |
| 门槛三·被碾压的个体 | ⚠️ 勉强过 | 酒保阿什顿：读了一封信，才知道自己是代码 |
| 触发器·口碑落差 | +1 | 1600 万美元成本、全球约 1850 万票房；同年被《黑客帝国》压过，土星奖最佳科幻片也输给了它 |
| 可数可验证的视觉线索 | +1 | 复用的脸、两次世界边缘，观众可自己暂停去数 |
| 全片钥匙 | +1 | 见下 |
| 原著 | 不计 | v1.3：有则加分、无则不扣。本片虽改编自 1964 年小说《Simulacron-3》，**本期不做原著对照，更不做电视剧版对照**，只在承诺段提一句当背景 |

**全片钥匙：「熟脸 = 上面还有一层」**
在这部片里，每一个从上层"进去"的人，都需要一具照着自己做出来的身体。所以每当观众认出一张熟悉的脸，就说明这张脸的上面还有一层世界。
- 第 1 次（第一幕交付）：1937 酒保阿什顿 ↔ 1999 技术员惠特尼
- 第 2 次（第二/三幕）：超市店员娜塔莎 ↔ 简·富勒
- 第 3 次（第四幕揭底）：霍尔 ↔ 2024 年的大卫
- 第 4 次（结局）：2024 那一层，还有没有熟脸？→ 交还解释权

**五幕规划**

| 幕 | 内容 | 主武器（v1.3 分流） |
|---|---|---|
| ① | 冷开场 + 承诺 + 自报家门 → 1937 那封信 → 富勒之死 → 带血的衬衫 → 不存在的女儿 → 交付钥匙 | W1 镜头 · W3 背景（黑色电影）· W4 伏笔 |
| ② | 霍尔第一次进入 1937 → 阿什顿读信 → 惠特尼 | W1 · W2 符号（信）· W6 台词 |
| ③ | 世界的边缘 ×2（阿什顿、霍尔）→ 恰饭位（如有） | W1 · 朋友接口：游戏引擎只渲染玩家看得到的地方 |
| ④ | 揭底：1999 也是模拟 → 简来自 2024 → 大卫借霍尔的身体杀了富勒 → 钥匙第 3 次 | W4 链式引爆 · 并列双解 |
| ⑤ | 结局：2024 醒来 → 屏幕缩成一道光 → 结尾三段式 | 落点：导演意图（观众也在一块屏幕前）|
