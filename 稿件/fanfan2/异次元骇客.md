## 拆片表

**一句话**：一个替老板造了一座城、在城里当神的人，查老板的命案时发现，自己也是别人造的，连杀死老板的那只手，都是头顶上的人借去的。

**这部片的乐趣**：被骗一次。前提（机器里有一座 1937 年的城）开场就亮出来了，真正的底（他脚下的"现在"也是假的，杀人的是他自己的身体）要到后段才揭。
所以观众和霍尔知道得一样多，镜头只跟霍尔，**不请观众找伏笔**，怪事只标"怪"、不点破。

**钩子挑的这件事**：造物主第一次走进自己造的城，就被自己造出来的酒保按在地上打（原片中段）。
第一句接上的是"造了一整座城"和"被城里一个酒保往死里打"，这就是反差。钩子只透露那封信让酒保看到了"可怕的真相"，不说真相是什么。
**这件事在结尾怎么回来**：开头是下面的人用拳头质问上面的人"凭什么"；结尾是下面的麦克贝恩恳求上面的人"别再来打扰我们"，
而这时霍尔自己也已经站到了上面。

**标签**：神/造物主。霍尔的台阶就是这个标签一级级被拿掉：
得意的造物主（"他们和你我一样真实"，拿来炫耀）→ 被自己的造物打 → 同一句话拿来替下面的人求情，想拔插头 → 发现自己头顶上也有人 →
发现自己是别人手里的木偶 → 对把他当神的酒保说"我不是神，我跟你一样" → 醒在上面。

**一件东西**：一根烟。霍尔不抽烟，别人却看见过他抽（怪，只标不解释）→ 揭底时收：抽烟的是借他身体的那个人。

**讲述顺序**：钩子（挨打）→ 片名 → "他叫道格拉斯·霍尔/挨那顿打的几天前" 倒回命案 → 那通没说完的电话、想不起来的一晚 → 冒出来的女儿 → 那根烟 →
为了老板留在系统里的信，他第一次下去（用"原来"交代那座城和借身体的规则）→ 接上钩子那一幕 → 拔不拔插头 → 收银台后面的女人 → 惠特尼没回来 →
世界的尽头 → 简的坦白 → 阿什顿叫他神 → 大卫下来 → 醒在上面 → 结尾。

**解释时机**：借身体的规则，在霍尔第一次睁眼时讲；"模拟里还套着模拟"，在简坦白时讲，用一句"楼上还有楼"打比方。

**结尾**：只落一个点，用这部片自己的词说：插头在谁手里不由你选，拿到插头以后把下面的人当不当人，由你选。
