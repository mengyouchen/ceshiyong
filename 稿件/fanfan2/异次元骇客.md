## 拆片表

**一句话**：一个替老板造了一座城、在城里当神的人，查老板的命案时发现，自己也是别人造的，连杀死老板的那只手，都是头顶上的人借去的。

**这部片的乐趣**：被骗一次。前提（机器里有一座 1937 年的城）开场就亮出来了；真正的底（他脚下的 1999 年也是假的，杀人的是他自己的身体）到 1:12 才揭。
所以观众和霍尔知道得一样多，镜头只跟霍尔，**不请观众找伏笔**，一路上的怪只标不解。

**钩子**：造物主走进自己造的城去取一封信，被城里的酒保按在地上打（58:00）。反差：造了一整座城 / 被城里一个酒保往死里打。
钩子只透露信里写着"可怕的真相"，不说是什么。正文讲到原位时接上，并补上开头没讲的：酒保已经开车到过世界的尽头。
**钩子那件事在结尾怎么回来**：那封让酒保动手的信，其实是写给霍尔的（1:25:34"这封信是写给我的"）；
开头是下面的人用拳头质问上面的人，结尾是下面的探长恳求上面的人"别再来打扰我们"，而这时霍尔已经醒在了上面。

**标签：神。** 霍尔的台阶就是这个标签一级级被拿掉：
得意的造物主（"他们就像你和我一样真实"，39:01，拿来炫耀）→ 看见老板拿这座城干了什么（葛先生的35年）→ 被自己造的人打 →
同一句话拿来替下面的人求情，要拔插头（1:02:25）→ 走到自己世界的尽头 → 知道自己是木偶 → 对把他当神的阿什顿说"我不是神，我跟你一样" → 醒在上面。

**一件东西：烟。** 葛先生的太太闻到烟味（05:50，富勒在他身体里）→ 霍尔在停尸房说不抽烟（10:44）→ 银行同事"什么时候戒的"（27:02）→
探长"坏习惯越染越多"（45:41，霍尔抽上了）。全程只标不解；简坦白"使用者下载进你"之后收：一具身体里住过谁，烟早就露了底。

**一个词：过瘾。** 富勒在城里"找乐子"（35:02）；霍尔给阿什顿讲游戏机，"永远那么过瘾"（1:25:29）；大卫杀人，"因为那很过瘾"（1:29:45）。
结尾靠它收：拿到插头的人，把下面当游戏机还是当人间。

**讲述顺序**：钩子（挨打）→ 片名 → "他叫道格拉斯·霍尔/挨那顿打的几天前"倒回命案那天早上 → 冒出来的女儿 → 遗嘱和那通被删的电话 →
第一次下去（"原来"交代那座城和借身体的规则）：银行、书店、酒吧 → 回来的得意 → 酒保敲诈、跳舞、被抓、酒保死、不在场证明 →
第二次独自下去：葛先生的35年、会员俱乐部、信给了酒保 → 接上钩子，补上世界尽头 → 拔不拔插头 → 简消失、娜塔莎 → 世界的尽头 → 简坦白 →
惠特尼没回来，阿什顿上来 → "我不是神"、游戏机、信是写给我的 → 大卫下来 → 麦克贝恩开枪 → 2024 → 结尾。

**原片顺序哪里调了**：只把 58:00 的挨打提到开头；其余照原片顺序，因为这部片自己的揭开顺序就是最好的揭开顺序。
麦克贝恩查娜塔莎、简给麦克贝恩打电话、惠特尼在 1937 年出事，霍尔都不在场：前一件用"霍尔不知道的是"，后两件等霍尔知道的时候用"原来"补。

**解释时机**：借身体的规则，在霍尔第一次睁眼成了银行出纳员时讲；"楼上还有楼"，在简坦白时讲；游戏机的比方，交给霍尔自己讲给阿什顿听。

**结尾**：只落一个点，用片子自己的"插头"和"游戏机"说。
