## 拆片表

**一句话**：一个替老板造了一座城的人，以为自己是这座城的神，最后发现自己也是别人造的——连杀死老板的那只手，都是被头顶上的"神"借去的。

**人物各自想要什么**
- 霍尔：先想证明自己没杀人；后来想保住下面那座城里的人；最后想要一个人，哪怕他自己不是"真的"。
- 富勒：在自己造的城里过年轻时的日子、追姑娘；发现真相后想关掉公司，留下一封信。
- 阿什顿（1937年的酒保）：读了信，想知道"你们凭什么"；后来爬到上面，想看看自己从哪儿来。
- 惠特尼：六年心血不能白费。
- 简：从上面下来，任务是冒充女儿接手公司再关掉它；爱上了霍尔。
- 大卫：在下面当神，杀人取乐。
- 麦克贝恩：查案；知道真相后，只求别再被打扰。

**霍尔的台阶（主线词"神"）**：得意的造物主（"他们和你我一样真实"）→ 发现老板这个造物主在下面寻欢作乐、让别人背锅 → 被自己的造物揍 → 想拔插头、不想再当这个神 → 发现自己头顶还有一个造物主 → 发现自己是那个神手里的木偶 → 对把他当神的阿什顿说"我不是神，我跟你一样" → 醒在上面，自己也成了别人头顶上的那一层。

**钩子**：一件事——霍尔第一次躺进机器，在1937年的一个银行出纳员身上醒来。第一句用"只是……就……"点出反差；把这件事演出来（柜台前的太太、同事递烟"你什么时候戒的"、被劝去吃午饭、街上报童喊号外）；事内加码（这座城里的一切都是他和老板造的，可没人知道）；他下来要干什么（找老板留下的东西，证明自己没杀人）；一句收住，只给方向（城里已经有人开始怀疑这个世界了）。前提就是这件事的核心，所以放进钩子；真正的底（"现在"也是假的、杀人的是他自己的身体）不碰。原片第25分钟的戏，钩子之后用"几天前"倒回，讲到时接回"故事开头的那一幕"。

**观众位置**：只跟霍尔。他不在场的戏，用"霍尔不知道的是……"或"原来……"拴回来。底和他一起揭开。只标"怪"：香烟、被删的留言、她"一直想让我认识你"、似曾相识、酒保那句多余的反问。

**主线**：词是"神/造物主"，长在叙述里，不报数；东西是香烟（钩子里同事那句"你什么时候戒的"→探长调侃"坏习惯越染越多"→"I stabbed him"之后收）。

**讲述顺序**：钩子 → 片名 → "几天前"：老板死了、他成了嫌疑人、留言里那半句话 → 接回钩子 → 书店老板 → 酒保 → 那封信 → 被自己的造物揍 → 拔插头 → 她是谁 → 世界的尽头 → 真相 → 上面的人下来 → 醒来。

**解释时机**：借身体的规则在钩子里随着事情讲；"那座城"在霍尔决定下去时从他的角度交代；"模拟里的模拟"在简坦白时讲。简揭开之前，"现在"不标年份。

**结尾角度**：只落一个点——这部片里当上"神"的人（富勒、大卫，连惠特尼也在护着自己的神座）都被它改变了，只有霍尔拒绝了它；可他醒来的地方，自己也成了别人头顶上的那一层。谁都可能是被造出来的，你手里握着别人的世界时把不把他们当人，决定了你自己算不算个人。
