## 拆片表

**一句话**：一个造了虚拟世界的人，为了查清自己有没有杀人，走进自己造的世界，最后发现自己也是被造出来的——连那只杀人的手，都是被别人借走的。

**人物各自想要什么**
- 霍尔：先想弄清那晚自己有没有杀人；后来想弄清什么才是真的；最后，想要一个人。
- 富勒：在自己造的1937年里找乐子；发现真相后想关掉公司，留下一封信。
- 阿什顿：读了信，开到世界尽头，想知道"你们凭什么"；后来爬到上面，想看看自己从哪儿来。
- 惠特尼：六年心血不能白费。
- 简：从上面下来，任务是冒充女儿接手公司再关掉它；爱上了霍尔。
- 大卫：把下面当游乐场，杀人取乐。
- 麦克贝恩：查案；知道真相以后，只求别再被打扰。

**霍尔的台阶**：被自己的作品揍的造物主（钩子）→ 想不起那一夜的嫌疑人 → 走进自己作品的造物主（"和你我一样真实"，骄傲）→ 想拔插头的造物主（"和你我一样真实"，求情）→ 怀疑身边的人 → 开到自己世界的尽头 → 发现自己是别人的木偶 → 被人当成"最真实的东西" → 醒在上面一层。

**钩子**：一件事——霍尔借着一个银行出纳员的身体，被他自己造出来的酒保揪住暴打。第一句点出反差（造物主被自己造出来的人打）；演这件事（酒保读了信、开到路被掐断的地方、回来揪住霍尔；原声一段）；事内加码（在这个世界里他连还手的力气都没有；计时器忘了开）；一句收住（他下来是为了查一桩谋杀案，头号嫌疑人就是他自己）。前提（有一个被造出来的世界）是这件事的核心，所以在钩子里；真正的底一点不碰。原片中段的戏，钩子之后用"几天前"倒回去，正文讲到时用"接下来就发生了故事开头的那一幕"接回。

**钩子之后**：片名定位一段 → 引子用片子的第一个画面：笛卡尔"我思故我在"，接上钩子里那个"是不是真的"的问题 → "几天前"，直接进霍尔。

**观众位置**
- 镜头只跟霍尔。他不在场的戏，只用"霍尔不知道的是……"或"原来……"拴回来。
- 钩子先送出去的：酒保后来会知道真相。所以霍尔第一次见他、他装傻时，观众心里有数。
- 和霍尔一起知道的：简是谁；他脚下的世界也是假的；杀富勒的是他自己的身体。
- 只标"怪"：香烟、被删掉的留言、她"一直想让我认识你"、似曾相识。

**主线**：词是"真的"（"这血是不是真的"→"和你我一样真实"两次→"你比我知道的任何东西都真实"→结尾）；东西是香烟，不提醒，在"I stabbed him"之后用"原来那几根烟/早就露了底"收。

**讲述顺序**：钩子之后从"几天前"按霍尔的目的走：老板死了 → 他成了嫌疑人 → 留言里那半句话 → 下去找"东西交给了谁"（书店老板 → 酒保 → 那封信）→ 接回钩子 → 拔插头 → 她是谁 → 世界的尽头 → 真相 → 上面的人下来 → 醒来。坐车、找人、跳舞几句带过；"富勒爱追姑娘"留到格里森掏出女人衣物时才想明白。

**解释时机**："那个系统"在霍尔决定下去时从他自己的角度交代；借身体的规则在他第一次在1937年睁眼时讲；"模拟里的模拟"在简坦白时讲。简揭开之前，不给"现在"标年份。

**原声**：只留交锋本身就是戏的地方；对话一律带出来，不报台词。

**结尾角度**：首尾相接——开头那个酒保揪着造物主问"这血是不是真的"，最后这个问题轮到霍尔问他自己；答案在简那句话里，也在片头那句"我思故我在"里。被造出来的人只作为霍尔的镜子。

**省掉的**：原片开场富勒交信那场（改为霍尔一路去发现）；麦克贝恩问惠特尼那场（霍尔不在场）；机房里阿什顿拿枪那场的结果（字幕没有交代）。
